## Architectural Patterns & Invariants

### 1. Hard Boundary Isolation (Zero Leakage)
- SIA Core must **NEVER** import or inspect `GroundTruthFrame`, `WorldState`, `VesselDynamics`, or `PhysicalOracle`.
- Boundary isolation is verified via AST parsing in `tests/unit/test_sia_boundary.py`.

### 2. Strict Null Semantics (No Zero-Coercion)
- Missing or degraded sensor channels must remain explicit `None` or `UNKNOWN`.
- Never coerce a missing sensor reading to `0.0`, `0.0 deg`, or `False`.

### 3. Bit-for-Bit Determinism
- Wall-clock time (`time.time()`, `time.sleep()`, `datetime.now()`) is **strictly forbidden** in the simulation core loop.
- All progression happens via discrete integer ticks: `clock.advance(10)` (10 ms / 100 Hz).
- All random processes must use isolated `DeterministicRNG` instances keyed by subsystem seeds.

### 4. Immutability
- Data contracts (`SensorFrame`, `GroundTruthFrame`, `Scenario`, `DecisionPayload`) use immutable Pydantic models (`frozen=True`) or immutable tuple fields.

## Error Handling

- **Simulation Core:** Fast-fail on invalid configurations during initialization (`ValueError`, `TypeError`).
- **Runtime Step Loop:** Graceful handling of sensor dropouts and noise degradation without unhandled exceptions.
- **Null Safety:** Explicit `if val is not None:` guards before mathematical operations.
