# Technology Stack

**Analysis Date:** 2026-09-17

## Overview

SIA Simulation is a high-performance, deterministic 100 Hz simulation testbed built in Python 3.12+ for validating the Safety & Intelligence Architecture (SIA) Core.

| Component | Technology | Version | Purpose |

| **Package Manager** | uv | `0.6+` | Sub-second venv, deterministic lockfile management |

## Frontend Stack (Workbench UI)

- **Architecture:** Zero-build ES Modules (`app.js`, `state.js`, `playback.js`, `modals.js`).
- **Rendering:** HTML5 Canvas 2D (60 FPS dials: Wind, Heel, Pitch, SOG/COG, Heave, Slamming).
- **Styling:** Vanilla CSS3 Night Bridge theme (high-contrast dark mode).
