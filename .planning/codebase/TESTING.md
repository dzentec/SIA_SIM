## Running the Tests

```bash
# Run all tests cleanly
uv run pytest

# Run with verbose output and coverage
uv run pytest -v --cov=sia_sim

# Run integration golden tests only
uv run pytest tests/integration/

# Run static type checking
uv run mypy src tests

# Run linter
uv run ruff check .
```
