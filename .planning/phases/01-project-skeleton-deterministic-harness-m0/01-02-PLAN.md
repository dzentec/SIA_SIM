      - `__init__(self, master_seed: int)`
      - `def get_channel(self, channel_name: str) -> np.random.Generator`: Returns an independent, deterministic PRNG stream keyed by channel name (e.g., 'wind', 'imu', 'gps').
      - `def spawn(self, num_streams: int) -> list[np.random.Generator]`: Spawns independent sub-generators.
    - Expose `RNGManager` in `src/sia_sim/core/__init__.py`.
    - Implement unit tests in `tests/unit/test_rng.py`:
      - Verify identical seeds produce identical numerical sequences across named channels.
      - Verify different seeds produce distinct sequences.
      - Verify drawing numbers from channel 'wind' does not alter the random sequence of channel 'imu'.

  </acceptance_criteria>
