<objective>
Implement strict, immutable Pydantic v2 models for `SensorFrame` and `GroundTruthFrame` — the two core data contracts used as the primary interface between the physics simulation and the SIA Core boundary.

`SensorFrame` is the ONLY data type that crosses the Simulation→SIA Core boundary (INV-01). It must represent all observable sensor channels with explicit `None` semantics for missing/failed signals (never coerced to 0.0 or False).

`GroundTruthFrame` represents the true physical state of the vessel and environment, owned by WorldModel/Dynamics and consumed by the Oracle only — never by SIA Core (INV-02).

Both models must be:
- Strict Pydantic v2 models (`model_config = ConfigDict(frozen=True, strict=True)`)
- Use `Optional[float]` / `Optional[int]` for sensor channels where `None` = missing/failed
- Fully typed and mypy-clean
- Export from the `contracts` package `__init__.py`
</objective>

## Task 2: Implement `SensorFrame` and `GroundTruthFrame` in `data.py`

Create `src/sia_sim/contracts/data.py` with the following models.

Key design rules:
- All sensor readings use `Optional[float]` where `None` means signal absent/failed — never use `0.0` as a sentinel for missing data.
- `SensorFrame` is frozen and immutable (read-only after construction).
- `GroundTruthFrame` is frozen and immutable.
- All models use `model_config = ConfigDict(frozen=True, strict=True)`.
- `sim_time_ms: int` — always integer milliseconds matching `SimulationClock`.

### Sub-models for SensorFrame

```python
class IMUReading(BaseModel):
    """Inertial Measurement Unit reading.

    None values indicate sensor failure or dropout — never coerced to 0.0.
    """

    model_config = ConfigDict(frozen=True, strict=True)

    roll_deg: float | None  # Roll angle in degrees. None = failed.
    pitch_deg: float | None  # Pitch angle in degrees. None = failed.
    roll_rate_deg_s: float | None  # Roll rate in deg/s. None = failed.
    pitch_rate_deg_s: float | None  # Pitch rate in deg/s. None = failed.
    yaw_rate_deg_s: float | None  # Yaw rate in deg/s. None = failed.
    accel_x_m_s2: float | None  # Longitudinal acceleration m/s². None = failed.
    accel_y_m_s2: float | None  # Lateral acceleration m/s². None = failed.
    accel_z_m_s2: float | None  # Vertical acceleration m/s². None = failed.
    fault: bool  # True if IMU is in fault state.


class GPSReading(BaseModel):
    """GPS/GNSS position and velocity reading."""

    model_config = ConfigDict(frozen=True, strict=True)

    latitude_deg: float | None  # WGS84 latitude degrees. None = no fix.
    longitude_deg: float | None  # WGS84 longitude degrees. None = no fix.
    sog_kt: float | None  # Speed over ground in knots. None = no fix.
    cog_deg: float | None  # Course over ground in degrees. None = no fix.
    hdop: float | None  # Horizontal DOP. None = no fix.
    fault: bool  # True if GPS is in fault state.


class WindReading(BaseModel):
    """Wind vane / anemometer reading."""

    model_config = ConfigDict(frozen=True, strict=True)

    apparent_wind_speed_kt: float | None  # Apparent wind speed knots. None = failed.
    apparent_wind_angle_deg: float | None  # Apparent wind angle degrees. None = failed.
    fault: bool  # True if wind sensor is in fault state.


class ActuatorState(BaseModel):
    """Actuator feedback state (rudder, sail controls)."""

    model_config = ConfigDict(frozen=True, strict=True)

    rudder_angle_deg: float | None  # Rudder angle degrees (+ starboard). None = no feedback.
    mainsheet_pct: float | None  # Mainsheet trim 0-100%. None = unknown.
    fault: bool  # True if actuator feedback is in fault state.
```

### SensorFrame (the key boundary type)

```python
class SensorFrame(BaseModel):
    """Observable sensor data — the ONLY type crossing Simulation→SIA Core boundary.

    INV-01: Only SensorFrame enters SIA Core.
    INV-02: Ground truth data is NEVER present here.

    None fields indicate signal absence/failure. They must never be coerced
    to 0.0 or False by consumers. SIA Core must handle None as 'no observation'.
    """

    model_config = ConfigDict(frozen=True, strict=True)

    sim_time_ms: int  # Simulation timestamp in integer milliseconds.
    imu: IMUReading  # IMU channel.
    gps: GPSReading  # GPS channel.
    wind: WindReading  # Wind channel.
    actuators: ActuatorState  # Actuator feedback channel.
    sequence_number: int  # Monotonically increasing frame counter.
```

### Sub-models for GroundTruthFrame

```python
class VesselState(BaseModel):
    """True physical state of the vessel."""

    model_config = ConfigDict(frozen=True, strict=True)

    x_m: float  # Position X in simulation frame (meters).
    y_m: float  # Position Y in simulation frame (meters).
    heading_deg: float  # True heading degrees (0=North, clockwise).
    sog_m_s: float  # Speed over ground m/s.
    cog_deg: float  # Course over ground degrees.
    heel_deg: float  # Heel angle degrees (+ to starboard).
    pitch_deg: float  # Pitch angle degrees (+ bow up).
    roll_rate_deg_s: float  # Roll rate degrees/s.
    yaw_rate_deg_s: float  # Yaw rate degrees/s.
    rudder_angle_deg: float  # True rudder angle degrees.


class EnvironmentState(BaseModel):
    """True environmental state."""

    model_config = ConfigDict(frozen=True, strict=True)

    true_wind_speed_m_s: float  # True wind speed m/s.
    true_wind_angle_deg: float  # True wind angle degrees (relative to North).
    wave_height_m: float  # Significant wave height meters.
    wave_period_s: float  # Wave period seconds.
    current_speed_m_s: float  # Sea current speed m/s.
    current_direction_deg: float  # Sea current direction degrees.


class GroundTruthFrame(BaseModel):
    """True physical state of the simulation world.

    INV-02: This MUST NOT enter SIA Core. Consumed only by Oracle.
    Owner: WorldModel / VesselDynamics.
    """

    model_config = ConfigDict(frozen=True, strict=True)

    sim_time_ms: int  # Simulation timestamp in integer milliseconds.
    vessel: VesselState  # True vessel physical state.
    environment: EnvironmentState  # True environmental state.
    sequence_number: int  # Monotonically increasing frame counter.
    active_event_ids: tuple[str, ...]  # Active scenario event IDs at this tick.
```

## Task 3: Write unit tests for data contracts

Create `tests/unit/test_contracts_data.py` covering:

1. **Construction tests** — valid `SensorFrame` and `GroundTruthFrame` can be created.
2. **None semantics tests** — all `Optional[float]` fields can be `None`; no zero-coercion occurs.
3. **Immutability tests** — mutating a frozen model raises `ValidationError` or `TypeError`.
4. **Strict type enforcement** — passing a `float` where `int` is expected raises `ValidationError`.
5. **Fault flag tests** — `fault=True` is valid alongside `None` sensor values.
6. **Round-trip serialization** — `model.model_dump()` → `SensorFrame.model_validate(...)` round-trips correctly.
7. **None preservation** — `model.model_dump()` preserves `None` (not converted to `0.0` or missing key).
