## Task 1: Implement `Scenario` and event models in `scenario.py`

Create `src/sia_sim/contracts/scenario.py`.

### Design rules
- `Scenario` must be frozen (INV-06: immutable during a run).
- `ScenarioEvent` holds timed events: `sim_time_ms`, `event_id`, `event_type`, and optional parameters.
- Event schedule is a `tuple` (immutable) of `ScenarioEvent` objects, sorted by `sim_time_ms`.
- `VesselConfig` holds initial physical parameters.

```python
class ScenarioEvent(BaseModel):
    """A timed event in a scenario schedule."""
    model_config = ConfigDict(frozen=True, strict=True)

    sim_time_ms: int        # When this event fires (simulation milliseconds).
    event_id: str           # Unique event identifier within the scenario.
    event_type: str         # Category: "wind_gust", "wave_impact", "rudder_stall", etc.
    parameters: dict[str, float | int | str | bool]  # Event-type-specific parameters.


class VesselConfig(BaseModel):
    """Initial vessel configuration for a scenario."""
    model_config = ConfigDict(frozen=True, strict=True)

    vessel_type: str        # e.g. "monohull_ior", "catamaran"
    loa_m: float            # Length overall in meters.
    beam_m: float           # Beam in meters.
    displacement_kg: float  # Displacement in kg.
    # Initial conditions
    initial_heel_deg: float         # Starting heel angle degrees.
    initial_heading_deg: float      # Starting heading degrees.
    initial_sog_kt: float           # Starting speed over ground knots.


class Scenario(BaseModel):
    """Immutable scenario specification.
    
    INV-06: Scenario is frozen during Run.
    Loaded and validated by ScenarioEngine before simulation starts.
    RUN MUST NOT START if Scenario validation fails.
    """
    model_config = ConfigDict(frozen=True, strict=True)

    scenario_id: str            # Unique identifier (e.g. "SIM-005").
    scenario_version: str       # Schema version for reproducibility.
    name: str                   # Human-readable name.
    description: str            # Human-readable description.
    duration_ms: int            # Total simulation duration in milliseconds.
    seed: int                   # Master PRNG seed for this run.
    vessel: VesselConfig        # Initial vessel configuration.
    events: tuple[ScenarioEvent, ...]  # Timed event schedule, sorted by sim_time_ms.
    # Environmental initial conditions
    initial_tws_kt: float       # True wind speed knots at T=0.
    initial_twa_deg: float      # True wind angle degrees at T=0.
    initial_wave_height_m: float    # Significant wave height meters at T=0.
    initial_wave_period_s: float    # Wave period seconds at T=0.
```

## Task 2: Implement decision and evaluation models in `evaluation.py`

Create `src/sia_sim/contracts/evaluation.py`.

### Three-response architecture (per HLD §7)

The system supports UP TO 3 candidate responses per decision cycle. This does not mean 3 separate simulation runs — it means 3 alternatives evaluated inside one SIA decision cycle.

```python
class RiskAssessment(BaseModel):
    """SIA Core risk assessment for the current sensor frame."""
    model_config = ConfigDict(frozen=True, strict=True)

    hazard_id: str | None           # Identified hazard, or None if no hazard.
    risk_score: float               # 0.0 (safe) to 1.0 (critical).
    confidence: float               # 0.0 to 1.0 confidence in assessment.
    evidence_ids: tuple[str, ...]   # Sensor frame fields that drove this assessment.


class CandidateResponse(BaseModel):
    """One candidate response from SIA Core."""
    model_config = ConfigDict(frozen=True, strict=True)

    response_id: str                    # Unique ID for this candidate.
    action_type: str                    # e.g. "REDUCE_SAIL", "ALTER_COURSE", "ALERT_CREW"
    rudder_command_deg: float | None    # Commanded rudder angle. None = no rudder command.
    sail_command_pct: float | None      # Sail trim command %. None = no sail command.
    priority_score: float               # Higher = preferred response.
    rule_ids: tuple[str, ...]           # SIA rules that generated this candidate.


class DecisionPayload(BaseModel):
    """Complete SIA Core decision output for one sensor frame.
    
    Contains risk assessment, up to 3 candidate responses, and the selected
    response after conflict resolution. This is the output of SIACore.process().
    """
    model_config = ConfigDict(frozen=True, strict=True)

    decision_id: str                            # Unique decision identifier.
    sim_time_ms: int                            # Decision timestamp.
    sensor_frame_sequence: int                  # Sequence number of input SensorFrame.
    risk_assessment: RiskAssessment             # Risk evaluation result.
    candidates: tuple[CandidateResponse, ...]  # 0-3 candidate responses.
    selected_response: CandidateResponse | None # Chosen response, or None if no action.
    conflict_resolution_note: str               # How conflicts were resolved (audit trail).
```

### Oracle and Evaluator contracts

```python
class OracleResult(BaseModel):
    """Independent oracle verdict based on ground truth (not SIA output).
    
    INV-03: Oracle does not use SIA decision to construct expected result.
    """
    model_config = ConfigDict(frozen=True, strict=True)

    scenario_id: str
    hazard_onset_ms: int | None         # When the hazard condition first met threshold.
    required_response_window_ms: int | None  # Latest acceptable response time (ms after onset).
    expected_action_type: str | None    # What SIA should ideally do.
    recovery_achieved: bool             # True if physical recovery conditions were met.
    safety_envelope_breached: bool      # True if hard safety limits were crossed.
    severity: str                       # "NONE", "LOW", "MEDIUM", "HIGH", "CRITICAL"


class EvaluationResult(BaseModel):
    """Objective PASS/FAIL evaluation comparing SIA output against Oracle expectations.
    
    INV-08: Evaluator observes; it does not correct SIA output.
    """
    model_config = ConfigDict(frozen=True, strict=True)

    scenario_id: str
    run_id: str
    verdict: str                        # "PASS" or "FAIL"
    detection_latency_ms: int | None    # Time from hazard onset to SIA response. None = not detected.
    false_positives: int                # Number of alerts with no corresponding hazard.
    false_negatives: int                # Number of missed hazard detections.
    safety_margin_pct: float            # How far inside the safety envelope SIA responded.
    notes: str                          # Human-readable evaluation summary.
```
