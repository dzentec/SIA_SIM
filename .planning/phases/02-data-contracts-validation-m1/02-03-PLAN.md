<objective>
Build a comprehensive schema validation test suite that:
1. Asserts strict rejection of invalid/edge-case inputs across all contract models.
2. Verifies immutability across all frozen models.
3. Verifies that `None` signals are preserved without zero-coercion at all serialization boundaries.
4. Tests cross-contract consistency (e.g. `SensorFrame.sequence_number` matches `DecisionPayload.sensor_frame_sequence`).

This plan depends on Plans 02-01 and 02-02 being complete.
</objective>

<tasks>

## Task 1: Edge-case rejection tests

Create `tests/unit/test_contracts_edge_cases.py`:

**SensorFrame edge cases:**
1. `sim_time_ms` must be `int` — passing `float` raises `ValidationError` (strict=True).
2. `sequence_number` must be non-negative — negative value raises `ValidationError`.
3. `imu=None` (missing entire IMU sub-model) raises `ValidationError` (required field).
4. `fault=True` with all sensor fields `None` is valid (complete IMU failure).
5. `fault=False` with some sensor fields `None` is valid (partial signal loss).

**GroundTruthFrame edge cases:**
1. `sim_time_ms` must be `int` — passing float raises `ValidationError`.
2. `active_event_ids=()` (empty tuple) is valid.
3. `active_event_ids` must be `tuple[str, ...]` — list raises `ValidationError` (strict=True).

**Scenario edge cases:**
1. `events=()` is valid (scenario with no timed events).
2. `duration_ms` must be positive integer.
3. `seed` can be any integer including 0 and negative (PRNG seeds are arbitrary).
4. `vessel.displacement_kg` must be a float or int — string raises `ValidationError`.

**DecisionPayload edge cases:**
1. `candidates` length cannot exceed 3 — enforce via `@model_validator` or `Annotated[..., MaxLen(3)]`.
2. `candidates=()` with `selected_response=None` is valid (no-action decision).
3. `selected_response` that is not in `candidates` is allowed (conflict resolution may pick).
4. `risk_score` outside [0.0, 1.0] — validate range and reject with `ValidationError`.
5. `confidence` outside [0.0, 1.0] — validate range and reject.

**EvaluationResult edge cases:**
1. `verdict` must be exactly `"PASS"` or `"FAIL"` — any other string raises `ValidationError`.
2. `false_positives` and `false_negatives` must be >= 0.
3. `detection_latency_ms=None` is valid (no detection occurred).
4. `safety_margin_pct` can be negative (envelope breached before SIA responded).

## Task 2: Immutability verification tests

In `tests/unit/test_contracts_edge_cases.py`, add immutability tests:

```python
import pytest
from pydantic import ValidationError

def test_sensor_frame_is_frozen(minimal_sensor_frame):
    with pytest.raises((ValidationError, TypeError)):
        minimal_sensor_frame.sequence_number = 999

def test_ground_truth_frame_is_frozen(minimal_ground_truth_frame):
    with pytest.raises((ValidationError, TypeError)):
        minimal_ground_truth_frame.sim_time_ms = 999

def test_scenario_is_frozen(minimal_scenario):
    with pytest.raises((ValidationError, TypeError)):
        minimal_scenario.seed = 999

def test_decision_payload_is_frozen(minimal_decision_payload):
    with pytest.raises((ValidationError, TypeError)):
        minimal_decision_payload.decision_id = "hacked"
```

## Task 3: None preservation / no zero-coercion tests

Critical invariant: `None` sensor values MUST NOT be coerced to `0.0`, `False`, or missing keys.

```python
def test_none_imu_fields_preserved_in_model_dump(minimal_sensor_frame):
    dumped = minimal_sensor_frame.model_dump()
    imu = dumped["imu"]
    assert imu["roll_deg"] is None, "None must not be coerced to 0.0"
    assert imu["roll_rate_deg_s"] is None, "None must not be coerced to 0.0"
    assert "roll_deg" in imu, "None field must not be omitted from dump"

def test_none_gps_fields_preserved_in_model_dump(minimal_sensor_frame):
    dumped = minimal_sensor_frame.model_dump()
    gps = dumped["gps"]
    assert gps["latitude_deg"] is None
    assert gps["sog_kt"] is None

def test_none_oracle_timing_preserved(minimal_oracle_result_no_hazard):
    dumped = minimal_oracle_result_no_hazard.model_dump()
    assert dumped["hazard_onset_ms"] is None
    assert dumped["required_response_window_ms"] is None
    assert "hazard_onset_ms" in dumped  # key must exist, not be omitted
```
