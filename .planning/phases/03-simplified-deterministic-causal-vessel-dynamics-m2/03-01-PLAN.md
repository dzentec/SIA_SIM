<objective>
Implement the deterministic environmental physics engine and `WorldModel` executing at 100 Hz (10 ms ticks).
The `WorldModel` computes ground-truth environmental state (wind speed/direction, gust dynamics, wave elevation/slope kinematics, sea current) and maintains active scenario event states.

Key requirements:
- Strictly deterministic and causal: identical simulation time and seed produce identical environmental vectors.
- Supports scenario events: `wind_gust`, `wave_impact`, `current_change`.
- Generates `EnvironmentState` matching the contract defined in `sia_sim.contracts.data`.
</objective>

<tasks>

## Task 1: Implement Environmental Physics in `environment.py`

Create `src/sia_sim/physics/environment.py`:
- `WindModel`: Computes true wind vector (speed in m/s, direction in degrees) with baseline wind plus active deterministic gust profiles (smooth half-cosine / 1-cos gust envelope).
- `WaveModel`: Computes deterministic wave encounter kinematics (significant wave height, period, wavelength, wave slope / orbital velocity) for wave impact events.
- `CurrentModel`: Computes sea current speed (m/s) and direction (degrees).

## Task 2: Implement `WorldModel` in `world.py`

Create `src/sia_sim/physics/world.py`:
- Initializes from `Scenario` parameters (`initial_tws_kt`, `initial_twa_deg`, `initial_wave_height_m`, etc.).
- `apply_events(events: Sequence[ScenarioEvent])`: Activates or updates environmental event modifiers (gusts, wave impacts).
- `step(time_ms: int) -> EnvironmentState`: Advances environmental state to `time_ms` and returns immutable `EnvironmentState`.
- `get_active_event_ids(time_ms: int) -> tuple[str, ...]`: Tracks active event IDs at current tick.

## Task 3: Package exports in `src/sia_sim/physics/__init__.py`

Export `WindModel`, `WaveModel`, `CurrentModel`, `WorldModel`.

## Task 4: Unit Tests for Environmental Physics and WorldModel

Create `tests/unit/test_physics_environment.py` and `tests/unit/test_world_model.py`:
- Test base wind and gust envelope response (smooth ramp up and decay).
- Test wave kinematic calculations (wave slope, encounter frequency).
- Test event application and expiration in `WorldModel`.
- Test bit-for-bit determinism across identical runs.
</tasks>
