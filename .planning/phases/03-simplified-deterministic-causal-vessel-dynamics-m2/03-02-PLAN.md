<objective>
Implement simplified deterministic causal 4-DOF vessel dynamics (surge, sway, yaw, roll) driven by environmental forces, sail aero, rudder hydro, and righting moments, integrated via fixed-step numerical integration (10 ms / 100 Hz).

Key requirements:
- Rigid-body planar motion with roll: captures heel-induced rudder stall and weather helm yaw moment (the fundamental physics of the broach precursor SIM-005).
- Deterministic and causal: zero reliance on wall-clock time, no asynchronous steps, bit-exact reproducibility.
- Fixed-step deterministic numerical integration (RK4 / semi-implicit Euler at $dt = 0.01\text{ s}$).
- Generates `VesselState` matching `sia_sim.contracts.data`.
</objective>

<tasks>

## Task 1: Implement Hydrodynamic & Aerodynamic Forces in `forces.py`

Create `src/sia_sim/physics/forces.py`:
- `apparent_wind(u: float, v: float, heading_deg: float, tws_m_s: float, twa_deg: float) -> tuple[float, float]`: Converts true wind + vessel velocity to apparent wind speed (m/s) and apparent wind angle (deg).
- `sail_forces(aws_m_s: float, awa_deg: float, mainsheet_pct: float, reef_ratio: float, sail_area_m2: float) -> tuple[float, float, float, float]`: Computes sail thrust $X_{sail}$, side force $Y_{sail}$, heeling moment $K_{sail}$, and yaw moment $N_{sail}$.
- `rudder_forces(u: float, rudder_angle_deg: float, heel_deg: float, rudder_area_m2: float) -> tuple[float, float]`: Computes rudder lateral force $Y_{rudder}$ and steering moment $N_{rudder}$, including heel-dependent rudder ventilation/loss-of-effectiveness.
- `hydrodynamic_damping(u: float, v: float, r: float, p: float, mass_kg: float) -> tuple[float, float, float, float]`: Computes hull resistance $X_H$, sway damping $Y_H$, yaw damping $N_H$, and roll damping $K_H$.
- `righting_moment(heel_deg: float, mass_kg: float, gm_m: float) -> float`: Computes hydrostatic restoring moment $K_{righting} = - m \cdot g \cdot GM \cdot \sin(\phi)$.

## Task 2: Implement Fixed-Step Numerical Integrator in `integrator.py`

Create `src/sia_sim/physics/integrator.py`:
- `rk4_step(state: np.ndarray, derivatives_fn: Callable[[np.ndarray, float], np.ndarray], dt: float, t: float) -> np.ndarray`: Classical 4th-order Runge-Kutta fixed-step integrator.

## Task 3: Implement `VesselDynamics` in `dynamics.py`

Create `src/sia_sim/physics/dynamics.py`:
- Holds internal state $[x, y, \psi, u, v, r, \phi, p]$.
- `step(dt_s: float, env: EnvironmentState, rudder_deg: float, mainsheet_pct: float) -> VesselState`: Computes equations of motion derivatives, advances state by $dt$, clamps angle wrap-arounds (0-360 for heading, -180..180 for heel), and returns immutable `VesselState`.
- `reset(initial_state: VesselConfig)`: Restores vessel to scenario initial conditions.

## Task 4: Package exports in `src/sia_sim/physics/__init__.py`

Export `VesselDynamics`, `apparent_wind`, `sail_forces`, `rudder_forces`, `rk4_step`.

## Task 5: Unit Tests for Forces and Dynamics

Create `tests/unit/test_physics_forces.py` and `tests/unit/test_vessel_dynamics.py`:
- Test apparent wind velocity triangle kinematics.
- Test sail lift/drag curve and heeling moment increase with wind speed.
- Test rudder stall and effectiveness reduction at high heel angles (>25°).
- Test steady-state sailing equilibrium (balanced helm).
- Test deterministic trajectory matching across multiple identical runs.
</tasks>
