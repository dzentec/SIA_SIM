<objective>
Implement core sensor degradation primitives (Gaussian noise, static bias, linear drift, latency FIFO buffer, dropout, frozen fault) and individual sensor channel generators (IMU, GPS, Wind, Actuators) that transform ground truth physical states into realistic raw sensor observations with seed-isolated PRNG streams.
</objective>

<tasks>

## Task 1: Implement Sensor Degradation Primitives in `src/sia_sim/sensors/degradation.py`

Create `src/sia_sim/sensors/degradation.py`:
- `DegradationConfig`: Pydantic/dataclass model defining noise std_dev, bias offset, drift rate (units/s), latency (ms), dropout probability, and freeze duration.
- `ChannelDegrader`: Stateful, deterministic transformer for a single numeric signal:
  - **Noise:** Adds Gaussian noise $\mathcal{N}(0, \sigma)$ sampled deterministically from an isolated `numpy.random.Generator` stream.
  - **Bias & Drift:** Adds static offset $b_0$ and time-varying drift $b(t) = b_0 + \text{drift\_rate} \cdot t$.
  - **Latency:** Deterministic FIFO queue delaying samples by exact integer milliseconds ($N = \text{latency\_ms} // 10$ ticks).
  - **Frozen Fault:** Holds previous output value constant when active.
  - **Dropout Fault:** Emits `None` (preserving strict null semantics) when active or on dropout trigger.

## Task 2: Implement Individual Channel Models (`imu.py`, `gps.py`, `wind.py`, `actuator.py`)

Create `src/sia_sim/sensors/imu.py`:
- `IMUSensorModel`: Generates `IMUReading` from `VesselState` (roll_deg, pitch_deg, roll_rate_deg_s, yaw_rate_deg_s, acceleration components computed via kinematics / gravity vector rotation). Applies per-axis noise, bias, and fault flags.

Create `src/sia_sim/sensors/gps.py`:
- `GPSSensorModel`: Generates `GPSReading` from `VesselState` (latitude_deg, longitude_deg, sog_kt, cog_deg, hdop). Supports GPS fix loss (all coordinates `None`, fault=True) and velocity noise.

Create `src/sia_sim/sensors/wind.py`:
- `WindSensorModel`: Generates `WindReading` from `EnvironmentState` and `VesselState` (calculating apparent wind speed in kt and apparent wind angle in deg). Applies anemometer noise, mast-motion distortion, and vane dropouts.

Create `src/sia_sim/sensors/actuator.py`:
- `ActuatorSensorModel`: Generates `ActuatorState` from vessel rudder position.
  - `rudder_angle_deg`: Standard rudder feedback sensor with potentiometer noise, bias, feedback latency, and disconnect faults.
  - `mainsheet_pct`: Defaults to `None` (reflecting that 95%+ of real yachts have no mainsheet/traveler position sensors; SIA Core MUST NOT depend on reading mainsheet sensor values). Optional feedback only if explicit winch telemetry is configured.

Create `src/sia_sim/sensors/__init__.py` exposing the public sensor models.
