<objective>
Implement the composite `SensorPipeline` that orchestrates all individual sensor channels, integrates with `RngHarness` for deterministic multi-channel seeding, processes scenario fault events (e.g. `sensor_dropout`, `sensor_noise`, `sensor_frozen`, `imu_failure`), and produces valid, immutable `SensorFrame` instances from `GroundTruthFrame`.
</objective>

<tasks>

## Task 1: Implement Composite `SensorPipeline` in `src/sia_sim/sensors/pipeline.py`

Create `src/sia_sim/sensors/pipeline.py`:
- `SensorPipeline`:
  - Instantiates individual channel models (`IMUSensorModel`, `GPSSensorModel`, `WindSensorModel`, `ActuatorSensorModel`), each bound to a dedicated seed channel from `RngHarness` (e.g. `imu_rng`, `gps_rng`, `wind_rng`, `actuator_rng`).
  - `process(gt: GroundTruthFrame, active_event_ids: tuple[str, ...]) -> SensorFrame`:
    - Evaluates any active sensor fault scenario events.
    - Runs all channel models synchronously.
    - Assembles and returns immutable `SensorFrame(sim_time_ms=gt.sim_time_ms, imu=..., gps=..., wind=..., actuators=..., sequence_number=...)`.
  - `reset()`: Resets all internal channel states, buffers, latency queues, and PRNG seeds to T=0 initial state.

## Task 2: Implement Sensor Channel Unit Tests in `tests/unit/test_sensor_channels.py`

Create `tests/unit/test_sensor_channels.py`:
- Test `IMUSensorModel` output under static upright, rolling, and pitching motion.
- Test `GPSSensorModel` coordinates, speed, and course conversion from vessel ground truth.
- Test `WindSensorModel` apparent wind calculation against theoretical vector algebra.
- Test `ActuatorSensorModel` feedback fidelity.
- Verify that ideal sensors with zero noise produce exact ground-truth matches.

</tasks>
