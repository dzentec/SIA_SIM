<objective>
Build exhaustive verification test suites for the sensor degradation pipeline:
1. End-to-end integration and frame synthesis (`test_sensor_pipeline.py`).
2. Bit-for-bit determinism, seed isolation, and statistical noise validation (`test_sensor_determinism.py`).
3. Complete fault injection modes: latency delay timing, dropouts with strict `None` semantics, frozen states, and fault flags (`test_sensor_faults.py`).
</objective>

<tasks>

## Task 1: Implement Pipeline Integration Tests in `tests/unit/test_sensor_pipeline.py`

Create `tests/unit/test_sensor_pipeline.py`:
- Feed a 1000-tick (10.0 s) stream of `GroundTruthFrame` generated by `WorldModel` and `VesselDynamics` into `SensorPipeline`.
- Assert continuous output of valid `SensorFrame` instances matching timestamp and monotonic sequence numbers.
- Assert strict isolation: ground truth internal attributes do not leak into `SensorFrame`.

## Task 2: Implement Sensor Determinism Tests in `tests/unit/test_sensor_determinism.py`

Create `tests/unit/test_sensor_determinism.py`:
- Verify two full sensor pipeline runs with identical master seeds produce 100% bit-identical `SensorFrame` streams.
- Verify changing master seed produces distinct noise realizations.
- Verify cross-channel independence (changing IMU noise settings does not affect GPS or Wind random sequences).
- Statistical check: sample 5000 noise values and verify sample mean $\mu \approx 0$ and sample standard deviation $\sigma \approx \sigma_{\text{config}}$.

## Task 3: Implement Fault Injection & Null Semantics Tests in `tests/unit/test_sensor_faults.py`

Create `tests/unit/test_sensor_faults.py`:
- **Latency Queue:** Apply 100 ms latency to GPS SOG; verify value emitted at $T$ matches ground truth at $T-100\text{ ms}$.
- **Dropout Fault:** Trigger sensor dropout on wind vane; verify `apparent_wind_speed_kt` and `apparent_wind_angle_deg` become `None` and `fault=True` without zero-coercion.
- **Frozen Sensor:** Trigger frozen IMU; verify roll and pitch values remain identical across 50 ticks despite changing physical ground truth.
- **Partial Failure:** Test IMU with only yaw rate failed (`yaw_rate_deg_s=None`), while roll and pitch continue outputting valid degraded measurements.
- **Absent Mainsheet Sensor:** Verify that by default `mainsheet_pct` is `None` (representing standard yacht hardware without winch telemetry) and that `SensorFrame` validation succeeds without error.

</tasks>
