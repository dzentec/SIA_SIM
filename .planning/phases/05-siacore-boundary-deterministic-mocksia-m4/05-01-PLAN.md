<objective>
Define the formal `SIACore` runtime `Protocol` contract and implement automated AST and runtime boundary enforcement tests ensuring that only `SensorFrame` can enter SIA Core and that no Ground Truth structures or physics internals are ever imported or accessible to SIA algorithms.
</objective>

<tasks>

## Task 1: Define `SIACore` Protocol in `src/sia_sim/sia/protocol.py`

Create `src/sia_sim/sia/protocol.py`:
- `SIACore(Protocol)`:
  - `def process(self, frame: SensorFrame) -> DecisionPayload: ...`
  - `def reset(self) -> None: ...`
- Docstrings documenting the hard architectural boundary (`INV-01`, `INV-02`).

Create `src/sia_sim/sia/__init__.py` exporting `SIACore`.

## Task 2: Implement AST & Runtime Boundary Enforcement Tests in `tests/unit/test_sia_boundary.py`

Create `tests/unit/test_sia_boundary.py`:
- **Static AST Analysis:** Inspect all Python files under `src/sia_sim/sia/` to verify zero imports of:
  - `GroundTruthFrame`, `VesselState`, `EnvironmentState`
  - `WorldModel`, `VesselDynamics`, `environment`, `forces`, `integrator`
- **Type Checking:** Verify that any implementation conforming to `SIACore` accepts `SensorFrame` and returns `DecisionPayload`.
- **Runtime Boundary:** Verify passing non-SensorFrame objects (e.g. `GroundTruthFrame`) to `SIACore.process()` is rejected by type checking and runtime validation.

</tasks>
