<objective>
Implement a deterministic, rule-based `MockSIA` conforming to `SIACore` that performs multi-layer evaluation on incoming `SensorFrame` streams: L0 Sensor Integrity, L2 Hazard Detection (`BROACH_PRECURSOR`), L3 Risk Assessment, and L4 Candidate Response Generation (0-3 candidates) with conflict resolution, producing structured `DecisionPayload` outputs.
</objective>

<tasks>

## Task 1: Implement `MockSIA` in `src/sia_sim/sia/mock_sia.py`

Create `src/sia_sim/sia/mock_sia.py`:
- `MockSIA(SIACore)`:
  - `__init__(heel_threshold_deg: float = 22.0, yaw_rate_threshold_deg_s: float = 2.0)`
  - `process(frame: SensorFrame) -> DecisionPayload`:
    - **L0 (Sensor Integrity):** Evaluates sensor health flags and `None` fields; adjusts `confidence` score (e.g. 1.0 down to 0.5 if wind or rudder sensor has failed).
    - **L2 (Hazard Detection):** Analyzes `frame.imu.roll_deg`, `frame.imu.roll_rate_deg_s`, and `frame.imu.yaw_rate_deg_s`. Detects `"BROACH_PRECURSOR"` when heel exceeds threshold and yaw/roll rates indicate uncommanded round-up.
    - **L3 (Risk Assessment):** Calculates `RiskAssessment(risk_score=..., confidence=..., severity=...)` mapping to `"NOMINAL"`, `"ADVISORY"`, `"WARNING"`, or `"CRITICAL"`.
    - **L4 (Candidate Responses):**
      - When hazard is detected, generates up to 3 candidate responses:
        1. `CandidateResponse(response_id="R-EASE-01", response_type="ease_mainsheet", priority=1, parameters={"ease_pct": 50.0})`
        2. `CandidateResponse(response_id="R-BEAR-01", response_type="bear_away", priority=2, parameters={"target_heading_delta_deg": 15.0})`
        3. `CandidateResponse(response_id="R-RUDDER-01", response_type="counter_rudder", priority=3, parameters={"rudder_target_deg": -15.0})`
      - Selects safest response based on sensor confidence and conflict resolution rules.
    - Assembles and returns immutable `DecisionPayload`.
  - `reset()`: Resets internal temporal filters and decision counters.

Expose `MockSIA` in `src/sia_sim/sia/__init__.py`.

## Task 2: Implement Unit Tests in `tests/unit/test_mock_sia.py`

Create `tests/unit/test_mock_sia.py`:
- **Nominal State Test:** Upright vessel with nominal sensors produces `hazard_detected=False`, severity `"NOMINAL"`, 0 candidate responses, `selected_response=None`.
- **Broach Precursor Detection Test:** Severe heel + roll rate triggers `hazard_detected=True`, hazard_type `"BROACH_PRECURSOR"`, severity `"CRITICAL"`, 3 candidate responses, and a selected response.
- **Sensor Integrity Degradation Test:** IMU or GPS dropouts lower the confidence score in `RiskAssessment`.
- **Determinism Test:** Identical `SensorFrame` sequence yields identical `DecisionPayload` trace.
