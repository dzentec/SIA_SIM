<objective>
Implement `RunRecorder` to capture synchronous 100 Hz simulation runs containing paired `(GroundTruthFrame, SensorFrame, DecisionPayload)` records, providing fast in-memory storage, Polars DataFrame conversion, and zero-copy trace export while maintaining strict data separation between Ground Truth and SIA observations.
</objective>

<tasks>

## Task 1: Implement `RunRecorder` in `src/sia_sim/recorder/run_recorder.py`

Create `src/sia_sim/recorder/run_recorder.py`:
- `SimulationRecord`: Data structure holding one tick's full snapshot (`gt`, `sf`, `decision`).
- `RunRecorder`:
  - `record(gt: GroundTruthFrame, sf: SensorFrame, decision: DecisionPayload) -> None`
  - `to_polars() -> tuple[pl.DataFrame, pl.DataFrame, pl.DataFrame]`:
    - Returns 3 separate Polars DataFrames: `df_ground_truth`, `df_sensor`, `df_decisions`.
  - `to_jsonl(path: str | Path) -> None`: Exports replayable JSON Lines records.
  - `reset()`: Clears in-memory records for new simulation runs.

Create `src/sia_sim/recorder/__init__.py` exporting `RunRecorder` and `SimulationRecord`.

## Task 2: Implement Unit Tests in `tests/unit/test_recorder.py`

Create `tests/unit/test_recorder.py`:
- **Record Ingestion Test:** Ingest 1000 ticks of simulation data and verify row counts match.
- **Polars Conversion Test:** Verify DataFrame columns, data types, null preservation, and timestamps.
- **Data Boundary Isolation Test:** Ensure `df_sensor` contains zero ground-truth columns.
- **Reset Test:** Ensure recorder reset completely clears buffers.

</tasks>
