<objective>
Implement the independent physical `SafetyOracle` that inspects continuous `GroundTruthFrame` sequences to determine ground-truth safety envelope breaches, physical hazard onset timestamps, required intervention time windows, expected optimal recovery actions, and recovery verification without any dependency or coupling with SIA decisions (INV-03).
</objective>

<tasks>

## Task 1: Implement `SafetyOracle` in `src/sia_sim/evaluator/oracle.py`

Create `src/sia_sim/evaluator/oracle.py`:
- `OracleConfig`: Pydantic/dataclass configuring physical safety thresholds:
  - `heel_hazard_deg: float = 25.0` (onset of broach precursor)
  - `heel_critical_deg: float = 45.0` (safety envelope breach / knockdown)
  - `yaw_rate_hazard_deg_s: float = 3.0` (severe uncommanded yaw round-up)
  - `max_allowed_response_window_ms: int = 3000` (time to respond before unrecoverable broach)
- `SafetyOracle`:
  - `evaluate(ground_truth_frames: Sequence[GroundTruthFrame], scenario_id: str) -> OracleResult`:
    - Scans frames chronologically to identify first `hazard_onset_ms` where heel or yaw rate exceeds safety threshold.
    - Determines maximum severity level reached (`NONE`, `LOW`, `MEDIUM`, `HIGH`, `CRITICAL`).
    - Checks if `safety_envelope_breached` occurs (e.g. heel exceeds `heel_critical_deg` at any point).
    - Checks if `recovery_achieved` occurs (vessel returns to nominal heel < 15° and yaw rate < 1.0 deg/s by end of scenario).
    - Identifies `expected_action_type` (e.g. `"EASE_MAIN"` or `"BEAR_AWAY"`).
    - Computes and returns immutable `OracleResult`.
  - `reset()`: Resets internal state for new scenario runs.

Create `src/sia_sim/evaluator/__init__.py` exporting `SafetyOracle` and `OracleConfig`.

## Task 2: Implement Oracle Unit Tests in `tests/unit/test_oracle.py`

Create `tests/unit/test_oracle.py`:
- **Nominal Run Test:** Flat calm/steady sailing trajectory yields `hazard_onset_ms=None`, `severity="NONE"`, `safety_envelope_breached=False`, `recovery_achieved=True`.
- **Broach Precursor Scenario Test:** SIM-005 ground truth stream correctly identifies hazard onset at exact tick where heel exceeds 25°, flags `severity="CRITICAL"`, and sets `expected_action_type="EASE_MAIN"`.
- **Envelope Breach Test:** Unmitigated trajectory with heel reaching 50° flags `safety_envelope_breached=True`.
- **Invariant INV-03 Test:** Verify `SafetyOracle` runs solely on `GroundTruthFrame` and has zero references to `SensorFrame` or `DecisionPayload`.
