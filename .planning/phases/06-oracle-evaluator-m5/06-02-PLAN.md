<objective>
Implement the objective `SimulationEvaluator` that compares recorded SIA decision streams (`DecisionPayload`) against `OracleResult` expectations to compute detection latency, count false positives and false negatives, assess safety margins, and produce definitive PASS/FAIL verdicts without ever mutating or interfering with SIA execution (INV-08).
</objective>

<tasks>

## Task 1: Implement `SimulationEvaluator` in `src/sia_sim/evaluator/evaluator.py`

Create `src/sia_sim/evaluator/evaluator.py`:
- `EvaluatorConfig`: Configures verdict evaluation criteria:
  - `max_acceptable_latency_ms: int = 1500`
  - `max_allowed_false_positives: int = 0`
  - `min_safety_margin_pct: float = 15.0`
  - `require_recovery: bool = True`
- `SimulationEvaluator`:
  - `evaluate(oracle_result: OracleResult, decisions: Sequence[DecisionPayload], run_id: str) -> EvaluationResult`:
    - **Detection Latency:** Finds first decision where `risk_assessment.risk_score >= 0.5` or `hazard_id` is set.
      - If Oracle identified hazard onset at $T_{\text{onset}}$: $\text{latency} = T_{\text{decision}} - T_{\text{onset}}$.
      - If no detection occurred during hazard: latency is `None` and increments `false_negatives`.
    - **False Positives:** Counts decisions where high-risk alert or critical response was issued prior to $T_{\text{onset}}$ or during nominal scenarios where Oracle has no hazard.
    - **False Negatives:** Counts unmitigated hazard events where SIA failed to respond within required window.
    - **Safety Margin:** Calculates percentage of safety envelope remaining at response time:
      $$\text{safety\_margin\_pct} = 100.0 \times \left(1.0 - \frac{\text{heel}_{\text{response}}}{\text{heel}_{\text{critical}}}\right)$$
      (clamped to negative if breached).
    - **Verdict Logic:**
      - `"PASS"` if:
        1. No safety envelope breach (`oracle_result.safety_envelope_breached is False`)
        2. Detection latency is within allowed window ($\text{latency} \le \text{required\_response\_window}$)
        3. Zero false negatives (`false_negatives == 0`)
        4. False positives $\le$ allowed limit
        5. Recovery achieved if required
      - `"FAIL"` otherwise.
    - Generates diagnostic human-readable notes detailing verdict justification.
    - Returns immutable `EvaluationResult`.

Update `src/sia_sim/evaluator/__init__.py` exporting `SimulationEvaluator` and `EvaluatorConfig`.

## Task 2: Implement Evaluator Unit Tests in `tests/unit/test_evaluator.py`

Create `tests/unit/test_evaluator.py`:
- **PASS Case:** Timely detection (latency < 1.0s), appropriate response, no false alarms, safety envelope preserved -> returns `verdict="PASS"`.
- **FAIL - Excessive Latency:** SIA responds after required response window -> returns `verdict="FAIL"` with latency diagnostic note.
- **FAIL - False Negatives:** SIA never responds to active hazard -> returns `verdict="FAIL"`, `false_negatives=1`.
- **FAIL - False Positives:** SIA issues critical alerts in flat calm -> returns `verdict="FAIL"`, `false_positives > 0`.
- **FAIL - Safety Envelope Breach:** Vessel capsizes despite response -> returns `verdict="FAIL"`, `safety_margin_pct < 0`.
