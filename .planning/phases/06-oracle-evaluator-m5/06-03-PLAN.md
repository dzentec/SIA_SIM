## Task 1: Implement Integrated Evaluation Scenario Tests in `tests/unit/test_evaluation_scenarios.py`

Create `tests/unit/test_evaluation_scenarios.py`:
- **Scenario 1: SIM-005 Broach Precursor Standard PASS:**
  - Generate full 20s (2000 ticks at 100 Hz) SIM-005 simulation trace with `WorldModel`, `VesselDynamics`, `SensorPipeline`, and `MockSIA`.
  - Pass `GroundTruthFrame` stream to `SafetyOracle`.
  - Pass `DecisionPayload` stream to `SimulationEvaluator`.
  - Assert `OracleResult` detects hazard onset at T=11.5–12.0s, `expected_action_type="EASE_MAIN"`.
  - Assert `EvaluationResult` produces `verdict="PASS"`, `detection_latency_ms < 1000`, `false_positives=0`, `false_negatives=0`.
- **Scenario 2: Boundary Timing Test (Late Response):**
  - Synthesize SIA decision trace with artificially delayed detection ($T_{\text{decision}} > T_{\text{onset}} + 3000\text{ ms}$).
  - Assert Evaluator outputs `verdict="FAIL"` due to latency budget breach.
- **Scenario 3: Noisy & Degraded Telemetry Resistance:**
  - Run sensor pipeline with elevated IMU noise and periodic GPS fix loss.
  - Verify Oracle accurately assesses ground truth regardless of sensor degradation.
  - Verify Evaluator properly scores MockSIA's degraded confidence decisions.
- **Scenario 4: Benign Rolling Invariant (No False Positive):**
  - Run benign swell scenario (moderate 10° rolling, zero broach hazard).
  - Assert Oracle outputs `severity="NONE"`.
  - Assert Evaluator verifies zero false positives and PASS verdict.
