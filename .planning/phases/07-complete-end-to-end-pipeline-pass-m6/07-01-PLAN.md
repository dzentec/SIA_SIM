<objective>
Implement the primary high-level `SimulationRunner` orchestrator and canonical `SIM-005` scenario preset definition, connecting WorldModel, VesselDynamics, SensorPipeline, SIACore, RunRecorder, SafetyOracle, and SimulationEvaluator into a synchronous 100 Hz simulation loop.
</objective>

<tasks>

## Task 1: Canonical SIM-005 Scenario Preset in `src/sia_sim/scenarios/sim005.py`

1. Create `src/sia_sim/scenarios/sim005.py` and `src/sia_sim/scenarios/__init__.py`:
   - `get_sim005_scenario(seed: int = 42) -> Scenario`:
     - Returns validated, frozen `Scenario` matching CORE-004 / SIM-005 specifications:
       - Vessel: IOR monohull (LOA 10.5m, Beam 3.2m, Displacement 4500kg, initial heading 65.0 deg, SOG 5.0 kt, initial heel -15.0 deg).
       - Environment: initial TWS 15.0 kt, TWA 0.0 deg, wave height 2.0m, wave period 6.0s.
       - Events:
         - Wave impact at T=10000ms (`impact_force_n=12000.0`, `impact_roll_moment_nm=-25000.0`, `duration_ms=2000`).
         - Wind gust at T=12000ms (`tws_kt=18.0`, `duration_s=4.0`, `direction_shift_deg=15.0`).
       - Duration: 20000ms (20s / 2000 ticks).
   - Helper function `load_scenario(path_or_name: str, seed: int = 42) -> Scenario` supporting predefined scenario IDs ("SIM-005", "SIM-BENIGN") or custom JSON file paths.

## Task 2: Core `SimulationRunner` Engine in `src/sia_sim/engine/runner.py`

1. Create `src/sia_sim/engine/__init__.py` and `src/sia_sim/engine/runner.py`:
   - Data class `SimulationRunResult`:
     - `scenario: Scenario`
     - `evaluation: EvaluationResult`
     - `oracle_result: OracleResult`
     - `recorder: RunRecorder`
     - `elapsed_wall_time_s: float`
     - `sim_speed_ratio: float` (simulated time / elapsed wall time)
   - Class `SimulationRunner`:
     - `__init__(sia_core: SIACore | None = None, oracle_config: OracleConfig | None = None, evaluator_config: EvaluatorConfig | None = None)`
     - `run(scenario: Scenario, run_id: str | None = None, apply_actuator_feedback: bool = True) -> SimulationRunResult`:
       - Initializes discrete 100 Hz step clock (`dt_s = 0.01`).
       - Instantiates `WorldModel`, `VesselDynamics`, `SensorPipeline` (seeded from `scenario.seed`), `RunRecorder`, `SafetyOracle`, and `SimulationEvaluator`.
       - Runs synchronous step loop for `scenario.duration_ms // 10` iterations:
         - Advances world physics and active events.
         - Steps vessel dynamics with current rudder and mainsheet actuator inputs.
         - Assembles `GroundTruthFrame`.
         - Converts ground truth to `SensorFrame` via `SensorPipeline`.
         - Feeds `SensorFrame` to `SIACore.process()`.
         - If `apply_actuator_feedback` is True and SIA returned commands, applies them to next tick actuators (simulating skipper execution).
         - Records `(gt, sf, decision)` into `RunRecorder`.
       - Evaluates ground truth trace with `SafetyOracle.evaluate(gt_frames, scenario.scenario_id)`.
       - Evaluates decision trace against oracle with `SimulationEvaluator.evaluate(oracle_result, decisions, run_id)`.
       - Returns structured `SimulationRunResult`.
