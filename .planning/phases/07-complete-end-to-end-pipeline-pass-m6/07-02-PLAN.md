<objective>
Implement the CLI entrypoint (`sia-sim` / `python -m sia_sim`) with support for scenario selection, custom seeds, Parquet/JSONL telemetry exports, rich console summary formatting, and verify via unit tests.
</objective>

<tasks>

## Task 1: Parquet & Multi-Format Telemetry Export in `src/sia_sim/recorder/run_recorder.py`

1. Extend `RunRecorder` with:
   - `export_parquet(output_dir: Path | str, prefix: str = "run") -> dict[str, Path]`:
     - Exports `ground_truth.parquet`, `sensors.parquet`, `decisions.parquet`, and `evaluation.json` into `output_dir`.
     - Uses PyArrow-backed Polars native fast Parquet writer.
   - `export_summary_json(path: Path | str, evaluation: EvaluationResult, oracle: OracleResult) -> Path`:
     - Writes comprehensive JSON run summary with metadata, timings, and PASS/FAIL score.

## Task 2: CLI Command Interface in `src/sia_sim/cli.py` & `src/sia_sim/__main__.py`

1. Create `src/sia_sim/cli.py`:
   - Argument parsing (using `argparse` standard library or `click`):
     - `scenario`: Scenario ID (default: "SIM-005") or path to JSON scenario file.
     - `--seed`, `-s`: PRNG master seed (default: 42).
     - `--output-dir`, `-o`: Directory to save telemetry and evaluation artifacts (optional).
     - `--export-parquet`: Flag to export Polars Parquet datasets.
     - `--export-jsonl`: Flag to export line-delimited JSON log.
     - `--quiet`, `-q`: Suppress detailed console progress, output verdict line only.
     - `--no-feedback`: Run in open-loop mode (do not apply SIA candidate responses to actuators).
   - Formatted console output:
     - Scenario banner, vessel info, duration, and seed.
     - Execution speed metric (e.g. `Simulated 20.0s in 0.35s (57.1x real-time)`).
     - Verdict box: `PASS` (green) / `FAIL` (red) with detection latency, false alarms, and safety margin.
     - Export paths if files were written.
   - Exit code: `0` on `PASS`, `1` on `FAIL` or error.
2. Create `src/sia_sim/__main__.py` forwarding to `cli.main()`.
3. Update `pyproject.toml` `[project.scripts]` to register `sia-sim = "sia_sim.cli:main"`.

## Task 3: Unit Tests in `tests/unit/test_cli.py`

1. Create `tests/unit/test_cli.py`:
   - Test CLI invocation with default arguments producing exit code 0 (PASS).
   - Test CLI with `--output-dir` and `--export-parquet` creating valid parquet files.
   - Test CLI with `--export-jsonl` creating valid JSONL log.
   - Test CLI with non-existent scenario raising clean error and exit code != 0.

</tasks>
