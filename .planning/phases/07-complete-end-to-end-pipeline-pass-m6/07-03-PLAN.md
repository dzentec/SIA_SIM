## Task 1: Golden Integration Suite in `tests/integration/test_golden_sim005.py`

1. Create `tests/integration/__init__.py` and `tests/integration/test_golden_sim005.py`:
   - **Test 1: `test_golden_sim005_end_to_end_pass` (GOLD-01, GOLD-02, GOLD-03):**
     - Load canonical SIM-005 scenario specification.
     - Execute through `SimulationRunner`.
     - Assert `result.evaluation.verdict == "PASS"`.
     - Assert `result.evaluation.detection_latency_ms <= 1500`.
     - Assert `result.evaluation.safety_margin_pct >= 15.0`.
     - Assert `result.evaluation.false_positives == 0` and `result.evaluation.false_negatives == 0`.
     - Assert `result.oracle_result.safety_envelope_breached is False`.
     - Assert `result.oracle_result.expected_action_type == "EASE_MAIN"`.
   - **Test 2: `test_golden_sim005_bit_for_bit_repeatability`:**
     - Execute 3 independent runs with seed=42.
     - Extract ground truth, sensor, and decision DataFrames.
     - Assert bit-for-bit equality across all recorded values (`assert df1.equals(df2)` and `assert df2.equals(df3)`).
   - **Test 3: `test_golden_sim005_performance_benchmark`:**
     - Execute 20s scenario (2000 steps at 100 Hz).
     - Assert execution completes in $< 2.0$ seconds on CPU ($> 10\times$ faster than real-time execution).
   - **Test 4: `test_golden_sim005_telemetry_data_isolation`:**
     - Verify `result.recorder.to_polars()` contains zero ground truth columns in `df_sensor`.
     - Verify all null semantics in sensor frames are strictly preserved (no zero-coercion).

</tasks>
