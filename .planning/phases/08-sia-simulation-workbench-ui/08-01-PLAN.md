# Plan 08-01: Workbench Backend Engine & Telemetry Streamer

## Objective
Implement the backend bridge and HTTP/JSON telemetry streaming service for the SIA Simulation Workbench, allowing the browser interface to run scenarios (SIM-005, Benign, custom), scrub 100 Hz step trajectories, trigger interactive skipper actions, and launch directly via `sia-sim --workbench`.

## Tasks

### Task 1: Create Workbench Package & HTTP Server
- Create `src/sia_sim/workbench/__init__.py` and `src/sia_sim/workbench/server.py`.
- Implement lightweight built-in HTTP server (`http.server` / WSGI / JSON API) with endpoints:
  - `GET /api/scenarios`: Returns available scenario presets (`sim005`, `benign`).
  - `POST /api/run`: Executes `SimulationRunner` on selected scenario & seed, returning the full 100 Hz timeline payload (Ground Truth, Sensors, SIA decisions, Oracle events, Evaluator verdict).
  - `POST /api/step`: Executes a single 10 ms discrete step for interactive stepping.
  - `POST /api/query-action`: Applies skipper contextual input (e.g. `sail_set="REEF_1"`) and recalculates MockSIA response.
  - `GET /`: Serves the static Workbench UI web application.

### Task 2: Integrate `--workbench` Flag into CLI
- Update `src/sia_sim/cli.py` to support `--workbench` / `-w` and `--port` (default `8050`).
- Print clean launch banner and open browser automatically if requested.

### Task 3: Unit Tests for Backend API
- Create `tests/unit/test_workbench_server.py` to verify:
  - Scenario list endpoint returns valid payloads.
  - Run endpoint executes SIM-005 and produces complete structured timeline data.
  - Skipper query endpoint successfully feeds context into SIA Core.

## Verification
- `uv run pytest tests/unit/test_workbench_server.py -v` passes cleanly.
- `uv run sia-sim --help` displays `--workbench` option.
