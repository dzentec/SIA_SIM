# Plan 08-02: Workbench UI 5-Zone Shell, Canvas Marine Dials & Lab Terminal

## Objective
Implement the complete single-screen frontend interface conforming strictly to `08-UI-SPEC.md`: Night bridge color palette (`#080c14` / `#111827` / `#00e5ff`), 60 FPS HTML5 Canvas marine dials (AWA/AWS wind dial, heel inclinometer, SOG/COG vectors), and the monospaced Ground Truth laboratory terminal.

## Tasks

### Task 1: HTML5 Shell & Design System (Vanilla CSS)
- Create `src/sia_sim/workbench/static/index.html` with standard semantic elements and unique element IDs.
- Create `src/sia_sim/workbench/static/css/workbench.css`:
  - 60-30-10 Night bridge palette with `#080c14` backdrop, `#162032` card surfaces, and `#1f2d47` borders.
  - 4px spacing scale (`xs: 4px` to `3xl: 64px`).
  - Strict typography rules (`Inter` for UI, `JetBrains Mono` for telemetry and monospace terminal).
  - Mode styling: `LIVE / OPERATION` (minimal high-contrast) vs `DEBUG / RESEARCH` (noise matrices & latency queues).

### Task 2: High-Precision HTML5 Canvas Marine Instruments
- Create `src/sia_sim/workbench/static/js/instruments.js`:
  - **AWA / AWS Circular Wind Gauge:**
    - Dual starboard green (`#00e676`) / port red (`#ff1744`) wind sectors ($0^\circ \dots \pm 180^\circ$).
    - High-visibility apparent wind angle pointer and digital speed display.
  - **Heel / Inclinometer Dial:**
    - Visual yacht hull cross-section tilting dynamically with roll angle.
    - Caution zone ($18^\circ$) and critical knockdown threshold ($25^\circ$) markers.
  - **SOG / COG Navigation Display:**
    - Vector compass rose with heading and speed over ground readout.
  - **Fault & Degraded Sensor States:**
    - Graceful dimming and `---` / amber `NO FIX` badge rendering when sensor values are `None`.

### Task 3: Ground Truth Lab Terminal (Zone 2) & SIA Decision Cards (Zone 4)
- **Zone 2 Lab Terminal:** Slate monospaced view (`#64748b` tint) displaying true TWS, TWD, wave elevation, true heel, and rudder hydro loss with explicit badge: `● SIMULATION ONLY — NOT AVAILABLE TO SIA`.
- **Zone 4 SIA Advisory Panel:**
  - Dominant Cyan card for primary recommended action (`BEAR AWAY`, `EASE MAIN`, etc.).
  - Compact cards for alternative candidate actions with confidence scores.

## Verification
- Page renders without console errors or external library dependencies.
- Instruments update smoothly at 60 FPS under simulated telemetry feed.
