# Plan 08-03: Temporal Debugger Scrubber, Interactive Query Loop & Verification

## Objective
Complete the interactive simulation loop in the Workbench UI: implement Zone 1 multi-track temporal scrubber (with event overlays), Zone 5 interactive skipper query loop with instant SIA recalculation, and the Oracle/Evaluator footer status bar.

## Tasks

### Task 1: Multi-Track Temporal Debugger (Zone 1)
- Create `src/sia_sim/workbench/static/js/timeline.js`:
  - Multi-track timeline canvas showing 0 to 30 seconds (3000 ticks at 100 Hz).
  - Visual tracks: Wind Gusts, Wave Impacts, Sensor Faults, Rudder Action, SIA Decision Points.
  - Interactive playback controls: `▶ Run`, `⏸ Pause`, `↺ Reset`, `⏯ Step (10 ms)`.
  - Scrubbing cursor: dragging cursor instantly updates all 3 visual columns to the exact time slice.

### Task 2: Interactive Skipper Query Loop (Zone 5)
- Create `src/sia_sim/workbench/static/js/query_loop.js`:
  - Renders contextual question box when SIA confidence drops or physical context is missing: `"Cannot determine sail configuration from sensors. Specify current set:"`.
  - Quick action chips: `[ FULL MAIN ]`, `[ REEF 1 ]`, `[ REEF 2 ]`, `[ STORM JIB ONLY ]`.
  - Clicking a chip dispatches the context update to SIA Core and re-evaluates the candidate decisions in real-time.

### Task 3: Oracle & Evaluator Status Footer
- Implement footer status bar in `src/sia_sim/workbench/static/js/app.js`:
  - Oracle Envelope safety margin indicator (`INTACT / BREACHED`).
  - Detection Latency counter (`X ms`, target `< 500 ms`).
  - False Alarms counter (`0`).
  - Definitive `VERDICT: PASS (M6)` / `VERDICT: FAIL` badge.

### Task 4: Automated Testing & Browser Verification
- Create `tests/unit/test_workbench_integration.py` to verify full workbench lifecycle:
  - Web server starts, serves HTML/JS/CSS assets with HTTP 200.
  - API handles timeline scrubbing, step execution, and query responses.
- Validate static files against linters.

## Verification
- `uv run pytest tests/unit/test_workbench_server.py tests/unit/test_workbench_integration.py -v` passes 100%.
- Launch `uv run sia-sim --workbench` and verify full interactive operation.
