# Plan 09-02: Sail Aerodynamics & 3D Center of Effort Engine

## Objective
Implement a multi-component 3D sail aerodynamics engine in `src/sia_sim/physics/sails/` according to the Sail Physics Specification: standalone `Sail` objects with nominal areas ($S_i$ in $\text{m}^2$), tack/head/clew geometry, dynamic boom kinematics $\theta_{\text{boom}}$, angle of attack $\alpha_i = AWA - \theta_{\text{boom}}$, dynamic 3D $CoE(x,y,z)$ coordinates, downwind blanketing, slot effect, and cross-product moment calculations $\vec{M} = \sum (\vec{r}_i \times \vec{F}_i)$.

## Tasks

### Task 1: Create `Sail` and Aerodynamic Polars Models
- Create `src/sia_sim/physics/sails/sail.py` with `SailType`, `SailConfig`, `SailState`.
- Create `src/sia_sim/physics/sails/polars.py` with aerodynamic coefficient curves $C_L(\alpha), C_D(\alpha)$ tailored for Main, Genoa, Jib, Code 0, Spinnaker.
- Implement dynamic boom/clew angle calculation $\theta_{\text{boom}}$ based on sheet trim ratio and apparent wind angle.
- Compute local 3D Center of Effort $CoE_i(x, y, z)$ dynamically shifting laterally as boom eases out ($y_{CoE} = R \sin\theta_{\text{boom}}$) and vertically during reefing.

### Task 2: Create `SailRig` & Interaction Engine (`rig.py`)
- Implement `SailRig` aggregating all active sails on board.
- Model mutual interaction:
  - Downwind blanketing / wind shadow (`blanket_ratio`) on $TWA > 130^\circ$.
  - Upwind slot effect / Venturi on $TWA = 30^\circ\dots 60^\circ$.
- Calculate total aerodynamic forces $\vec{F}_{\text{sails}} = [F_x, F_y, F_z]$ and 3D moments $\vec{M}_{\text{sails}} = \sum (\vec{r}_i \times \vec{F}_i)$ ($M_x$ heel, $M_y$ pitch, $M_z$ yaw / weather helm).

### Task 3: Integrate with `forces.py` and `dynamics.py`
- Refactor `forces.py` to delegate sail calculations cleanly to `SailRig`.
- Update `VesselDynamics` to apply the full 3D aerodynamic forces and moments into the 6-DOF / 4-DOF equation solver.

### Task 4: Unit Test Suite for Sail Aerodynamics
- Create `tests/unit/test_sail_aerodynamics.py` covering all acceptance criteria from the spec:
  - TWA 180° headsail drop removes $F_y$ and increases weather helm $M_z$.
  - Easing boom at TWA 90° rotates force vector and shifts $y_{CoE}$ outboard.
  - Genoa vs Spinnaker A2 tack shifts $x_{CoE}$ forward and changes $C_L/C_D$.
  - Reef 1 drops $z_{CoE}$ and reduces heeling moment $M_x$.
