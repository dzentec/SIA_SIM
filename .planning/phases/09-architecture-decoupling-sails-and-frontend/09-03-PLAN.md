# Plan 09-03: Safety Channel Status & End-to-End Regression Validation

## Objective
Implement MDA v2.2 Addendum requirements (`SafetyChannelStatus`: `WIRED_VERIFIED`, `WIRELESS_ADVISORY`, `MIXED`) in data contracts and sensor pipeline, update the telemetry serializer, and execute full end-to-end regression validation ensuring 100% test suite PASS.

## Tasks

### Task 1: Update Contracts with `SafetyChannelStatus`
- Add `SafetyChannelStatus` enum in `src/sia_sim/contracts/data.py`.
- Add `safety_channel_status: SafetyChannelStatus` field to `SensorFrame` (defaulting to `WIRED_VERIFIED`).

### Task 2: Sensor Pipeline Channel Status Evaluation
- Update `src/sia_sim/sensors/pipeline.py` to evaluate sensor hardware connectivity:
  - If any critical IMU operates over wireless/unverified channel -> `WIRELESS_ADVISORY`.
  - If all active critical sensors are wired RS-485 -> `WIRED_VERIFIED`.
- Propagate status through `SensorPipeline.synthesize()` into output `SensorFrame`.

### Task 3: Full End-to-End Regression Test
- Run full pytest test suite across all 9 phases.
- Validate SIM-005 golden trace bit-for-bit repeatability and PASS verdict.

## Verification
- `uv run pytest` passes all tests across the repository.
- Verify `SensorFrame.safety_channel_status` serialization matches MDA v2.2 specification.
