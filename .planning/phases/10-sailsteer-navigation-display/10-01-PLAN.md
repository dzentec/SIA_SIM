# Plan 10-01: SailSteer Canvas Renderer & Mathematical Engine

## Objective
Implement `SailSteerRenderer` and `SailSteerController` in `src/sia_sim/workbench/static/js/sailsteer.js` conforming strictly to `SailSteer_BG.md` v2.0 with a 7-layer rendering pipeline, offscreen canvas compass rose caching, physical angle damping, full mathematical wind triangle resolution, and strict null safety.

## Tasks

### Task 1: Create `SailSteerController` & Schema Validation
- Implement validation and normalization for `SailSteerTelemetry` JSON structure.
- Implement analytical formulas:
  - Apparent to True Wind conversion:
    $$V_{tx} = AWS \cdot \sin(AWA),\quad V_{ty} = AWS \cdot \cos(AWA) - STW$$
    $$TWS = \sqrt{V_{tx}^2 + V_{ty}^2},\quad TWA = \text{atan2}(V_{tx}, V_{ty})$$
    $$TWD = (HDG + TWA) \pmod{360}$$
  - Speed Through Water $STW$ calculation.
  - Relative current drift angle $\theta_{\text{drift}} = (\text{Current Dir} - HDG)$ and length clamping $L = \text{clamp}(Speed \times 25, 20, 120)$.
  - Laylines angles $\theta_{\text{lay\_port}} = TWD - TWA_{\text{opt}}$, $\theta_{\text{lay\_stbd}} = TWD + TWA_{\text{opt}}$.
  - Waypoint relative bearing $\theta_{\text{wpt}} = ((WPT\_BRG - HDG) + 360) \pmod{360}$ and steering error $(WPT\_BRG - HDG)$.

### Task 2: Implement `SailSteerRenderer` 7-Layer Canvas Pipeline (60 FPS)
- **Layer 0 (Static Background):** Dark background (`#0A0D12`), radial concentric graduation rings, static lubber line ticks.
- **Layer 1 (Rotating Compass Rose):** Heading-up compass scale (0°–359°) with cardinal points (N, E, S, W) rotated by `-HDG * PI / 180`. Cached on an offscreen canvas for high performance.
- **Layer 2 (Tack & Gybe Sectors):**
  - Upwind Port (`#FF3B30`, $-TWA_{\text{opt}} \dots 0^\circ$) and Starboard (`#34C759`, $0^\circ \dots +TWA_{\text{opt}}$).
  - Downwind Port ($180^\circ - TWA_{\text{opt\_down}} \dots 180^\circ$) and Starboard ($-180^\circ \dots -180^\circ + TWA_{\text{opt\_down}}$).
  - **Fixed relative to boat hull** (do NOT rotate with compass rose).
- **Layer 3 (Wind Dynamic Elements):**
  - Laylines (Port & Starboard) drawn from center towards compass perimeter.
  - Apparent Wind Pointer `A` (`#0066FF`) and True Wind Pointer `T` (`#0066FF`) with tack coloring (Green if $TWA > 0$, Red if $TWA < 0$).
- **Layer 4 (Boat Fixed Frame & Waypoint):**
  - Central stylized yacht silhouette fixed vertically upwards.
  - Top white heading readout box `[ HDG ]`.
  - Bright neon green waypoint rhombus marker (`#00FF66`) rendered when $GPS\text{ Lock} = \text{true}$ and $Waypoint \neq \text{null}$.
- **Layer 5 (Vectors & Markers):**
  - Deep Sky Blue (`#00BFFF`) current drift vector with arrowhead and speed readout.
- **Layer 6 (UI Overlay & Null Safety):**
  - Digital readout formatting adhering strictly to Section 5.2 of `SailSteer_BG.md` (leading zeros for courses, `---` on `null`).
