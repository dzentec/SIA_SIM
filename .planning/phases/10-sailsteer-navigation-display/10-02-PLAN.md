# Plan 10-02: Workbench UI 5-Zone Layout, CSS Styling & Slide Viewport Controller

## Objective
Update the central column of the Workbench UI to host both the 6-Dial Marine Console and the B&G SailSteer 5-zone display inside an animated sliding viewport (`.instruments-slider-viewport`), controlled by a segmented mode toggle (`[ ⊞ 6 DIAL CONSOLE ]` ⟷ `[ 🧭 SAILSTEER B&G ]`).

## Tasks

### Task 1: Update HTML Structure (`index.html`)
- In `zoneSensorView` (Block 4), add a segmented mode switcher in the card header:
  - Button `btnView6Dial` (`data-view="6dial"`)
  - Button `btnViewSailSteer` (`data-view="sailsteer"`)
- Wrap the instrument views in:
  - `.instruments-slider-viewport`
    - `.instruments-slider-track`
      - Slide 1 (`.instruments-slide.slide-6dial`): The existing 6-Dial Marine Console grid and sensor strip.
      - Slide 2 (`.instruments-slide.slide-sailsteer`): The authentic 5-zone B&G SailSteer Layout:
        - Zone 1: Top Status Bar (Local Time, GPS Lock, Depth, Mag Var, Display Mode).
        - Zone 2: Left Wind Data Dashboard (SOG, TWA, AWA, TWS, TWD, VAR).
        - Zone 3: Central SailSteer Canvas Widget (`canvas#sailSteerCanvas`).
        - Zone 4: Bottom Navigation Data Bar (STW, HDG, WPT DIST, WPT BRG, Laylines P/S, WPT Name).
        - Zone 5: Right Quick Bar (SOG, COG, POS, DEPTH, TIME LOC, STEUERN, ETW).
- Include `<script src="/js/sailsteer.js"></script>`.

### Task 2: CSS Styling & Hardware-Accelerated Sliding (`workbench.css`)
- Implement CSS for `.instruments-slider-viewport`, `.instruments-slider-track` with `transform: translateX(0%)` vs `transform: translateX(-50%)` and smooth `cubic-bezier(0.4, 0, 0.2, 1)` easing.
- Apply high-contrast night-bridge maritime styling:
  - Obsidian dark background (`#0A0D12`), borders (`#162032`), Port Red (`#FF3B30`), Starboard Green (`#34C759`), Wind Royal Blue (`#0066FF`), Neon Waypoint (`#00FF66`), Sky Blue Drift (`#00BFFF`).
  - Monospace telemetry typography (`JetBrains Mono`) and crisp status indicators.

### Task 3: App Orchestration & Keyboard Controls (`app.js`)
- Bind click events on `btnView6Dial` and `btnViewSailSteer`.
- Support keyboard shortcut (e.g. `Tab` or `KeyS` when not in input) to flip between 6-Dial and SailSteer modes.
- Save active view mode in `AppState.instrumentsViewMode`.

## Verification
- Verify smooth sliding transition in browser without layout shifts or canvas distortion.
