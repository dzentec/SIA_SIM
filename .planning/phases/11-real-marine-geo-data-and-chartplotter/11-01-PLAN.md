# Plan 11-01: DAE Core Contracts, Math Engine & Meteo/GRIB2 Pipeline

## Objective
Implement foundational Pydantic schemas, mathematical vector conventions (meteorological wind vs. oceanographic current), asynchronous Open-Meteo REST pipeline with retry/gather, GRIB2 fallback reader, and in-memory TTL caching per `.init_docs/real_geo_data.md`.

## Tasks

### Task 1: DAE Pydantic Data Contracts (`src/sia_sim/dae/schemas.py`)
- Define `DataSource` Literal (`open-meteo`, `grib2`, `netcdf`, `gebco`, `s57`, `none`).
- Implement immutable models:
  - `WindData`: `tws_knots`, `twd_deg`, `gusts_knots`, `u_component`, `v_component`.
  - `WaveData`: `significant_height_m`, `period_s`, `direction_deg`.
  - `CurrentData`: `speed_knots`, `direction_deg`, `u_m_s`, `v_m_s`.
  - `NavigationData`: `depth_m`, `nearest_hazard_dist_nm`, `bottom_type`.
  - `DataQuality`: component source flags, `is_degraded: bool`, `notes: list[str]`.
  - `UnifiedEnvironmentFrame`: canonical v1.0 frame with ISO 8601 UTC `Z` timestamp and `position: dict`.
  - `FrameRequest`: validation for latitude `[-90, 90]`, longitude `[-180, 180]`, `use_grib_fallback`, `vessel_draught_m`.

### Task 2: Cache Layer (`src/sia_sim/dae/cache.py`)
- Implement `UnifiedCache` using `cachetools.TTLCache`:
  - 0.05° x 0.05° grid rounding (`round(lat, 2)`, `round(lon, 2)`).
  - Meteo TTL: 900s (15 min), maxsize: 4096.
  - Hazard TTL: 300s (5 min), maxsize: 4096.

### Task 3: Meteo & GRIB2 Pipelines (`src/sia_sim/dae/pipelines/`)
- `MeteoPipeline` (`meteo.py`):
  - Parallel `asyncio.gather` for Open-Meteo Marine and Weather Forecast endpoints with exponential retry.
  - Meteorological wind conversion (direction from where wind blows):
    $$u = -\text{TWS}_{\text{m/s}} \cdot \sin(\text{TWD}_{\text{rad}}), \quad v = -\text{TWS}_{\text{m/s}} \cdot \cos(\text{TWD}_{\text{rad}})$$
  - Oceanographic current conversion (direction towards which current flows):
    $$u = +\text{SPD}_{\text{m/s}} \cdot \sin(\text{DIR}_{\text{rad}}), \quad v = +\text{SPD}_{\text{m/s}} \cdot \cos(\text{DIR}_{\text{rad}})$$
  - Explicit unit conversion: `ocean_current_velocity` (km/h) to knots ($\times 0.539957$) and m/s ($/ 3.6$).
- `Grib2Pipeline` (`grib2.py`):
  - Read local NOAA GFS GRIB2 via `xarray` and `cfgrib`.
  - Longitude normalization to $0\dots 360^\circ$.
  - Nearest neighbor interpolation for $u_{10}, v_{10}$ vector components.

### Task 4: Unit Testing (`tests/unit/test_dae_meteo.py`)
- Test meteorological wind vector decomposition and reciprocal reconstruction ($u, v \to \text{TWS}, \text{TWD}$).
- Test oceanographic current vector decomposition ($u, v \to \text{SPD}, \text{DIR}$).
- Test longitude wrapping (e.g., $\text{lon} = -45^\circ \to 315^\circ$).
- Test mock HTTP failures triggering GRIB2 fallback and proper `DataQuality` degradation flags.
