# Plan 11-02: Spatial Pipelines: GEBCO Bathymetry & S-57 Hazard Spatial Index

## Objective
Implement GEBCO GeoTIFF bathymetry reader with $2\times 2$ bilinear interpolation, multi-chart S-57 ENC hazard parser with attribute filtering (`CATWRK`, `VALSOU`), WKB conversion, Shapely `STRtree` spatial indexing, and `FrameAssembler` fail-soft integration.

## Tasks

### Task 1: GEBCO Bathymetry Pipeline (`src/sia_sim/dae/pipelines/bathymetry.py`)
- Open GeoTIFF on startup via `rasterio`.
- Implement `get_depth_m(lat, lon)` reading only a $2\times 2$ pixel window around the coordinate.
- Perform bilinear interpolation between the 4 grid nodes.
- Enforce strict null-safety: return `None` (never `0.0`) on missing data, out-of-bounds, or reader errors to prevent false "aground" triggers.
- Return positive depth in meters ($-\text{value}$ for GEBCO bathymetry where negative is depth).

### Task 2: S-57 ENC Hazard Pipeline (`src/sia_sim/dae/pipelines/s57.py`)
- Support multi-chart directory scanning for `.000` S-57 ENC cells.
- Extract hazard layers: `WRECKS`, `UWTROC`, `OBSTRN`, `LNDARE`, `COALNE`, `SLCONS`, `PIPSOL`, `CBLSUB`, `RESTRN`, `MORFAC`.
- Apply domain filters:
  - `WRECKS`: filter dangerous categories `CATWRK ∈ {2, 4}` (dangerous wreck, mast visible).
  - `UWTROC`, `OBSTRN`: filter depth threshold $\text{VALSOU} \le \text{draught} + \text{safety\_margin}$.
- Convert OGR geometries to Shapely geometries using high-speed `ExportToWkb()` (not JSON).
- Apply `shapely.make_valid()` to repair invalid geometries.
- Build spatial index using `shapely.strtree.STRtree`.
- Implement `nearest_hazard_nm(lat, lon, max_search_nm=30.0)`:
  - Longitude bounding box scaling by latitude: $\text{lon\_margin} = \frac{\text{margin}}{60 \cdot \cos(\text{lat})}$.
  - In-polygon check: return `0.0 NM` if point is inside a hazard geometry (`g.contains(pt)`).
  - Geodesic distance calculation via `pyproj.Geod(ellps="WGS84")`.

### Task 3: Frame Assembler & Fail-Soft Logic (`src/sia_sim/dae/assembler.py`)
- Combine Meteo, Bathymetry, and S-57 pipelines.
- Execute sync operations (`rasterio`, `GDAL`, `STRtree`) via `asyncio.to_thread()`.
- Evaluate degradation status: set `is_degraded: true` if any primary source fails or falls back.
- Produce fully validated `UnifiedEnvironmentFrame`.

### Task 4: Spatial Verification Tests (`tests/unit/test_dae_spatial.py`)
- Test GEBCO reader with synthetic mock GeoTIFF fixture asserting bilinear interpolation accuracy.
- Test S-57 bounding box width scaling at high latitudes (e.g. $\text{lat} = 60^\circ$ vs $\text{lat} = 0^\circ$).
- Test S-57 polygon containment returning `0.0 NM`.
- Test `VALSOU` and `CATWRK` filtering on mock S-57 features.
- Test `FrameAssembler` fail-soft behavior when bathymetry or hazard data is missing.
