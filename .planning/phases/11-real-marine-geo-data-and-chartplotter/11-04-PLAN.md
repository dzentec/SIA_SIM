# Plan 11-04: Tactical Marine Chartplotter Display in Workbench UI

## Objective
Implement an authentic Tactical Marine Chartplotter UI view (conforming to modern B&G Zeus / Raymarine Axiom tactical displays) in the central console of the SIA Simulation Workbench, rendering at 60 FPS with layered MapLibre/Canvas graphics, multi-mode view toggles, night/day tactical themes, and live environment provider switching.

## Tasks

### Task 1: Chartplotter Viewport & 3-Way Mode Switcher (`index.html`, `workbench.css`, `chartplotter.css`)
- Extend the central Workbench console header with a 3-way sliding view toggle:
  `[ ⊞ 6 DIAL CONSOLE ]` ⟷ `[ 🧭 SAILSTEER B&G ]` ⟷ `[ 🗺️ TACTICAL CHARTPLOTTER ]`.
- Create responsive HTML5 Canvas and Map container inside the sliding viewport.
- Implement high-contrast **Day Mode** and authentic **Night Tactical (Red/Black) Mode**.

### Task 2: Multi-Layer Chartplotter Rendering Engine (`chartplotter.js`)
- **Layer 0 (Basemap & Depth Gradients):** Render coastline, land polygons, and depth color gradations ($>50\text{m}$, $20–50\text{m}$, $5–20\text{m}$, $<3\text{m}$ shallow alert).
- **Layer 1 (S-57 Navigation Features & Safety Contours):** Render safety contour lines, underwater rocks (`+`), dangerous wrecks, and IALA-A/B lateral buoys (red/green markers).
- **Layer 2 (Tactical Laylines & Waypoints):** Draw Port (Red) and Starboard (Green) layline corridors based on $TWD$ and polar optimum angles $TWA_{\text{opt}}$, active route legs, and cross-track limits.
- **Layer 3 (Vessel & Motion Vectors):**
  - Render own ship silhouette with true heading $HDG$ orientation.
  - Draw speed/course-over-ground $COG/SOG$ velocity leader ray (scaled to 1/5/10 min projection).
  - Draw current drift arrow and range rings ($0.25, 0.5, 1.0, 2.0\text{ NM}$).
  - Draw historical breadcrumb track.
- **Layer 4 (Display Orientation Modes):** Support **North-Up**, **Head-Up** (boat fixed facing top, map rotating at $-HDG$), and **Course-Up** (map rotating at $-COG$).
- **Layer 5 (Tactical Data Boxes):** Render corner numeric telemetry cards ($SOG$, $COG$, $Depth$, $TWS$, $TWA$, $AWS$, $DTW$, $XTE$).

### Task 3: Interactive Environment & Region Controls (`app.js`, `server.py`)
- Add Environment Source control modal / panel in Workbench UI:
  - Toggle: `[ Synthetic Data | Real Geo Data ]`.
  - Geographic Region Presets: *"Solent & Isle of Wight"*, *"Biscay / Brittany"*, *"Cote d'Azur / Nice"*, *"San Francisco Bay"*, *"New York Harbor"*.
  - Manual Lat/Lon coordinate entry and map click-to-place start position.
  - Real-time data source status badges (`Open-Meteo: 18.2 kt`, `GEBCO: 38.5 m`, `S-57: OK`).
- Stream updated geographic position and bathymetry in 100 Hz Workbench WebSocket telemetry.

### Task 4: Verification & UI Testing (`test_workbench_chartplotter.py`)
- Unit test chartplotter coordinate projections and layer transformations.
- Verify smooth 3-way viewport slide transitions between 6-Dial, SailSteer, and Chartplotter.
- Validate telemetry updates in both Synthetic and Real Geo modes across all orientation options (North-Up, Head-Up, Course-Up).
