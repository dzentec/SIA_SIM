# Plan 12-01: Rig & Sail Data Contracts, Enums & Strict Validation

## Objective
Define and validate strict, immutable Pydantic v2 / dataclass schemas in `src/sia_sim/contracts/sails.py` according to Section 2 of `COCKPIT & RIG CONTROL_control.md` v2.0. This establishes the structural contract boundary separating rope/sail statuses, signed traveler positions, discrete furler metrics, and full rig telemetry.

## Tasks

### Task 1: Implement Separated Enums & Data Contracts in `contracts/sails.py`
- Define `RopeStatus` (`OK`, `SLACK`, `TAUT`, `OVERLOAD`, `CLAMPED`, `BROKEN`).
- Define `SailStatus` (`OK`, `LUFFING`, `ATTACHED`, `STALL`, `OVERLOAD`, `FURLED`).
- Implement `RopeControlInput`:
  - `rope_id: str`
  - `target_trim: float` (0.0 .. 1.0)
  - `clamped: bool`
  - `ease_rate: float = 1.0`
- Implement `RopeState`:
  - `id: str`, `side: Literal["port", "starboard", "center"]`, `group: Literal["jib", "main", "reef", "rig"]`
  - `target_trim: float`, `actual_trim: float`, `clamped: bool`
  - `length_m: float`, `speed_m_s: float`, `accel_m_s2: float`
  - `tension_n: float`, `max_working_load_n: float`, `breaking_load_n: float`
  - `status: RopeStatus`
- Implement `TravelerState`:
  - `id: str = "traveler"`
  - `target_pos: float` (-1.0 .. 0.0 .. +1.0)
  - `actual_pos: float`
  - `speed_m_s: float`, `clamped: bool`, `status: RopeStatus`
- Implement `FurlerState`:
  - `id: str = "jib_furler"`
  - `line_trim: float` (0.0 .. 1.0), `line_length_m: float`, `drum_turns: float`
  - `furled_ratio: float` (0.0 .. 1.0), `area_ratio: float` (1.0 - furled_ratio)
  - `status: RopeStatus`
- Implement `SailState`:
  - `sail_id: str`, `effective_area_m2: float`, `area_ratio: float`
  - `angle_of_attack_deg: float`, `twist_deg: float`, `camber_ratio: float`
  - `lift_force_n: float`, `drag_force_n: float`, `center_of_effort_z: float`
  - `reef_level: int`, `status: SailStatus`
- Implement `RigState` aggregate:
  - `timestamp_ms: int`, `ropes: dict[str, RopeState]`, `traveler: TravelerState`, `furler: FurlerState`, `sails: dict[str, SailState]`, `wind: dict[str, Any]`

### Task 2: Schema Validation & Invariant Tests
- Create `tests/unit/test_sails_ropes_contracts.py` testing:
  - Contract instantiations and strict type constraints.
  - Serialization to dict/JSON and deserialization roundtrips.
  - Bounds checks: `target_trim` in [0, 1], `target_pos` in [-1, 1], `area_ratio + furled_ratio == 1.0`.
  - Rejection of invalid status mixing (e.g. `RopeStatus.LUFFING` must not exist).

## Verification
- Run `uv run pytest tests/unit/test_sails_ropes_contracts.py`.
