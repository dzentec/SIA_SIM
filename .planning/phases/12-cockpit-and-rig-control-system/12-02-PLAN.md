# Plan 12-02: Rig Kinematics, Winch Inertia & Clutch/Stopper Physics Engine

## Objective
Implement physics calculations for winches, stoppers (clutches), furler drum mechanics, traveler movement, and dynamic aerodynamic interactions in `src/sia_sim/physics/sails/rig.py` and `sail.py` conforming to Section 3 of `COCKPIT & RIG CONTROL_control.md` v2.0.

## Tasks

### Task 1: Implement Winch Inertia & Clutch Model (`rig.py`)
- Implement `WinchModel`:
  - Enforce `clamped == True` -> $d(\text{actual\_trim})/dt = 0$, strictly preserving `actual_trim` while allowing `tension_n` to vary based on external forces.
  - Implement load-dependent speed:
    $$v_{\text{desired}} = \text{sign}(\text{target\_trim} - \text{actual\_trim}) \cdot v_{\text{winch}}$$
    $$\text{load\_factor} = \text{clamp}(1.0 - \frac{T_{\text{rope}}}{SWL}, 0.1, 1.0)$$
    $$v_{\text{desired}} \leftarrow v_{\text{desired}} \cdot \text{load\_factor}$$
  - Implement acceleration clamping with drum inertia $a_{\text{winch\_max}}$.
  - Update `actual_trim`, `speed_m_s`, `length_m`.
- Implement `TravelerModel`:
  - Rate-limited movement in signed $[-1.0, 1.0]$ range.
  - Effective main angle offset: $\Delta \alpha = \text{traveler\_pos} \cdot \Delta \phi_{\text{max}}$.
- Implement `FurlerModel`:
  - Conversion from `line_trim` to `line_length_m`, drum turns, `furled_ratio`, and `area_ratio`.
  - Additional drag penalty on furled sail: $C_{D,\text{furled}} = C_{D,0} + \text{furled\_ratio} \cdot C_{D,\text{penalty}}$.

### Task 2: Implement Rig-to-Sail Aerodynamics & Status Evaluator (`sail.py`, `rig.py`)
- Integrate Boom Vang to calculate `twist_deg` and vertical $C_L(z), C_D(z)$ adjustments.
- Integrate Outhaul to calculate `camber_ratio` reduction and profile flattening.
- Integrate Cunningham to calculate luff tension and dynamic shift in `stall_angle_deg`.
- Implement discrete reefing geometry transitions (`reef_level` 0, 1, 2) recalculating $A_{\text{eff}}$ and $CoE_z$.
- Implement dynamic status transition functions:
  - `RopeStatus`: `SLACK` ($T < T_{\text{slack}}$), `OK`, `TAUT` ($T > T_{\text{taut}}$), `CLAMPED`, `OVERLOAD` ($T > SWL$), `BROKEN` ($T > T_{\text{breaking}}$).
  - `SailStatus`: `FURLED` ($A_{\text{ratio}} < 0.01$), `LUFFING` ($\alpha < \alpha_{\text{luff}}$), `ATTACHED`, `OK`, `STALL` ($\alpha > \alpha_{\text{stall}}$), `OVERLOAD`.

### Task 3: Physics Unit & Verification Tests
- Create `tests/unit/test_rig_physics.py` covering:
  - `test_winch_rate_limit`: `actual_trim` step bounded by rate limits.
  - `test_winch_load_factor`: speed drop under high tension load.
  - `test_winch_accel_limit`: bounded acceleration.
  - `test_clutch_lock`: `clamped=True` freezes `actual_trim` regardless of `target_trim`.
  - `test_clutch_load_growth`: tension increases under aerodynamic load while clamped.
  - `test_traveler_signed_range`: signed movement bounded to $[-1.0, 1.0]$.
  - `test_furler_chain`: monotonic progression from `line_trim` to `area_ratio`.
  - `test_status_transitions`: verification of `LUFFING` -> `OK` -> `STALL` and `OVERLOAD` vs `BROKEN`.
