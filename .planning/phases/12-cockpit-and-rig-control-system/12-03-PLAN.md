# Plan 12-03: Rig Control JSON API & Preset Interlock Orchestrator

## Objective
Implement HTTP/WebSocket endpoints for rig control commands, telemetry streaming, and multi-step preset orchestration with safety interlocks (e.g. Reefing Dock scenarios) conforming to Section 5 of `COCKPIT & RIG CONTROL_control.md` v2.0.

## Tasks

### Task 1: Rig Controller & Preset Execution Engine (`engine/rig_controller.py`)
- Implement `RigController`:
  - Process batch rope and traveler control inputs with validation.
  - Reject unknown IDs (`INVALID_ROPE_ID`) or out-of-bounds parameters (`INVALID_RANGE`).
  - Check for broken lines (`ROPE_BROKEN`).
- Implement `PresetOrchestrator`:
  - Manage reefing presets (`FULL_MAIN`, `REEF_1`, `REEF_2`).
  - Execute 7-step sequence with safety checks (Interlocks):
    1. Check that `mainsheet` is eased below threshold (`mainsheet_actual_trim <= 0.3`). If not, return error `PRESET_INTERLOCK_FAILED` (`MAINSHEET_NOT_EASED`).
    2. Unclamp `main_halyard`.
    3. Ease `main_halyard` to reef mark.
    4. Trim `reef_line_N` to 100%.
    5. Tension `main_halyard` to working tension.
    6. Clamp all stoppers.
    7. Update `SailState` (recalculated area, $CoE_z$, twist, stall angle).
  - Provide preset step status in telemetry for UI progress indicators.

### Task 2: REST / WebSocket Endpoints in Server (`web/server.py`)
- `POST /api/v1/controls/rig`:
  - Accepts `{"timestamp_ms": int, "controls": [...]}`.
  - Updates rig target intents and clutch states.
- `POST /api/v1/controls/preset`:
  - Accepts `{"timestamp_ms": int, "preset": str, "params": {...}}`.
  - Returns `ACCEPTED` (with steps & interlocks) or `REJECTED` (with failure reason).
- `GET /api/v1/telemetry/rig`:
  - Returns current complete `RigState` JSON payload.

### Task 3: Integration & Error Handling Tests (`tests/integration/test_rig_api.py`)
- `test_controls_roundtrip`: POST controls and verify corresponding state transition in GET telemetry.
- `test_preset_reef_1_success`: verify successful reef execution when mainsheet is eased.
- `test_preset_reef_1_interlock_rejection`: verify HTTP 409 rejection if mainsheet is sheeted in tight.
- `test_error_handling`: verify standard error codes (`INVALID_ROPE_ID`, `INVALID_RANGE`, `ROPE_BROKEN`).
