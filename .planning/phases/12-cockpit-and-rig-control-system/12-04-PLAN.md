# Plan 12-04: SIA Simulation Workbench Cockpit UI (Dual-Bar Ropes, Traveler & Reefing Dock)

## Objective
Implement high-contrast, responsive cockpit and rig control UI components in SIA Simulation Workbench (`cockpit.js`, `cockpit.css`, `index.html`) conforming to Section 4 of `COCKPIT & RIG CONTROL_control.md` v2.0 with strict WCAG AA accessibility, separated identification and load color channels, centered bipolar traveler, and interactive Reefing Dock.

## Tasks

### Task 1: Dual-Bar Rope Widget & Layout Implementation (`cockpit.js`, `cockpit.css`)
- Build the 3-column Cockpit Control Layout:
  - **Port Column:** `JIB SHEET PORT` [P], `JIB FURLER`, `CUNNINGHAM`, Jib Status Indicator.
  - **Center Column:** Helm readout, central bipolar **Traveler Slider** (`-100% .. 0 .. +100%`).
  - **Starboard Column:** `MAIN SHEET` [MAIN], `BOOM VANG`, `JIB SHEET STARBOARD` [S], Main Status Indicator.
  - **Bottom Dock:** `REEFING DOCK` (`Main Halyard`, `Reef 1`, `Reef 2`, `Outhaul`, Preset Buttons `[FULL MAIN]`, `[REEF 1]`, `[REEF 2]`).
- Implement the **Dual-Bar Rope Widget**:
  - **Top Bar (Trim):** Fill corresponds to `actual_trim`, pointer marker indicates `target_trim`, percentage and length readouts.
  - **Bottom Bar (Load):** Fill and gradient based on $T_{\text{rope}} / SWL$:
    - 0–60%: `#34C759` (green)
    - 60–85%: `#FFCC00` (yellow)
    - 85–100%: `#FF3B30` (red)
    - >100%: flashing pulse alert (`OVERLOAD`).
  - **Clutch Toggle Button:** `[🔒 CLAMPED]` / `[🔓 UNCLAMPED]` state.
  - **Step Controls:** `[EASE]` / `[TRIM]` buttons for discrete adjustments.
  - **Dual Color Channel System:**
    - Left identification stripe with line ID color (Orange for mainsheet, Blue for port jib, Green for stbd jib, Yellow-Black zebra for vang, etc.).
    - Load bar strictly uses load gradient colors to prevent visual ambiguity.
  - **Side-aware Port / Starboard Jib Sheet dimming:** Automatically dim inactive (windward) sheet based on tack.

### Task 2: Reefing Dock Modal & Preset Script Orchestrator UI
- Implement modal/dock drawer for reefing controls.
- Connect preset buttons `[FULL MAIN]`, `[REEF 1 (75%)]`, `[REEF 2 (50%)]`.
- Render step-by-step progress and display toast/alert banner if interlock check fails (e.g. `Mainsheet must be eased below 30% before dropping halyard`).

### Task 3: Accessibility & Workbench Integration (`app.js`, `index.html`)
- Guarantee WCAG AA compliance:
  - Every rope widget has text labels `[P]`, `[S]`, `[MAIN]`, line name, numerical load in Newtons and SWL.
  - Distinct border/striping patterns for rope types.
- Bind `cockpit.js` to live simulation telemetry stream and user input events.
- Unit and DOM verification tests for widget rendering and state updates.

## Verification
- Test interactive slider dragging, clutch toggling, and preset clicks in browser workbench.
- Verify zero JavaScript console errors during live 100 Hz simulation.
