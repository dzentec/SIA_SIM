**SIA Simulation** — высокоточный детерминированный физико-сенсорный испытательный стенд (100 Гц) для валидации и верификации ядра предиктивной безопасности яхты **Safety & Intelligence Architecture (SIA) Core**. 

Стенд непрерывно генерирует гидродинамику живого моря, кинематику судна и синтетический поток сенсорных наблюдений (`SensorFrame`), тестируя реакцию SIA Core на развитие критических ситуаций (включая сценарий брочинга **SIM-005**) с независимым арбитражем через **Oracle Engine**.

## 🎯 Архитектура и ключевые инварианты

```
  ┌─────────────────────────────────────────────────────────────────────────┐
  │                         SIA SIMULATION ENGINE                           │
  │                                                                         │
  │   ┌───────────────────────────┐         ┌───────────────────────────┐   │
  │   │  Living Ocean Environment │  ────▶  │   4-DOF Vessel Dynamics   │   │
  │   │  (Wind/Waves/Sea Current) │         │   (Surge/Sway/Yaw/Roll)   │   │
  │   └───────────────────────────┘         └───────────────────────────┘   │
  │                 │                                     │                 │
  │                 ▼                                     ▼                 │
  │        ┌─────────────────────────────────────────────────────┐          │
  │        │         GroundTruthFrame (Physical Reality)         │          │
  │        └─────────────────────────────────────────────────────┘          │
  │                 │                                     │                 │
  │                 ▼                                     ▼                 │

  │   │  (Noise/Drift/IMU/GPS/HW) │         │    (Independent Ground    │   │
  │   │                           │         │      Truth Arbitrage)     │   │
  │   └───────────────────────────┘         └───────────────────────────┘   │

                    │ SensorFrame ONLY                    │

                    ▼                                     ▼
  ┌───────────────────────────────────┐     ┌───────────────────────────┐
  │             SIA CORE              │     │         EVALUATOR         │
  │   Real-time Predictive Hazard     │────▶│    Autonomous Pass/Fail   │
  │    & Skipper Interactive Loop     │     │     Verification Matrix   │
  └───────────────────────────────────┘     └───────────────────────────┘
```

### Архитектурные принципы:
1. **Строгая изоляция границы (Hard Boundary — INV-01, INV-02)**:
   - В SIA Core поступает **исключительно** структура `SensorFrame`.
   - Данные `GroundTruthFrame`, состояние гидродинамики и внутренние параметры мира **структурно изолированы** и никогда не передаются в SIA Core.
2. **100% Детерминизм и побитовая воспроизводимость**:
   - Дискретный шаг часов симуляции `SimulationClock` ровно **10 мс (100 Гц)**.
   - Нулевая зависимость от системного времени (wall-clock time).
   - Индивидуальные независимые потоки псевдослучайных чисел (PRNG) для каждого сенсорного канала и возмущения.
3. **Единый источник истины для параметров яхты (Single Source of Truth)**:
   - Геометрия, масса, длина (LOA), ширина (Beam), водоизмещение и парусное вооружение зафиксированы в каноническом `DEFAULT_VESSEL_CONFIG` (`Monohull IOR 10.5m`).
   - Пресеты мира управляют **только** состоянием гидрометеорологической среды.

## ⚡ Быстрый старт

### Требования
- Python 3.12+
- [uv](https://github.com/astral-sh/uv) (быстрый менеджер пакетов и виртуальных окружений)

### 1. Установка и запуск
```bash
# Клонирование репозитория
git clone https://github.com/dzentec/SIA_SIM.git
cd SIA_SIM

# Синхронизация зависимостей
uv sync

# Запуск интерактивного Веб-Верстака (Workbench)
uv run sia-sim --workbench --port 8080
```
Откройте в браузере: **`http://localhost:8080`**

### 2. Запуск верификации сценария в CLI
```bash
# Запуск эталонного сценария SIM-005 (Broach Precursor Golden Scenario)
uv run sia-sim --scenario SIM-005

# Запуск с кастомным сидом и длительностью
uv run sia-sim --scenario SIM-005 --seed 42 --duration 20
```

### 3. Запуск полного набора тестов
```bash
uv run pytest -v
```

## 🧭 Пресеты живого морского мира (World Presets)

В симуляторе реализованы 4 реалистичных фоновых состояния океана с непрерывным волновым и ветровым шумом:

| Пресет | Ветер ($TWS$) | Волна ($H_s$) | Период ($T_p$) | Динамика судна |
| :--- | :--- | :--- | :--- | :--- |
| **`harbour`** | 4.0 kt | 0.2 m | 3.0 s | Спокойная защищенная гавань, легкая рябь, плавный ход |
| **`cruise`** | 13.0 kt | 1.0 m | 4.5 s | Умеренный галфвинд, крен ~12°, стабильный ход 5.8 kt |
| **`fresh`** | 21.0 kt | 2.1 m | 5.0 s | Свежий бриз, крутая волна, выраженная бортовая и килевая качка |
| **`gale`** | 28.0 kt | 3.2 m | 6.5 s | Штормовое море, высокий риск брочинга, аэрация и срыв руля |

> **Принцип чистого окружения:** Пресеты создают фоновую живую динамику моря. Аномалии (шквалы, слеминг, отказы датчиков) не навязываются пресетом, а добавляются пользователем на интерактивном таймлайне.

│  [ Fresh   | Gale   ] │  [ COMPASS   ] [ HEAVE ]  [ SLAM  ]    │   [ REEF 2 ]   [STORM]│

└────────────────────────────────────────────────────────────────────────────────────────┘

### Основные функциональные блоки:

1. 🌊 **World Preset & Simulation Settings (Слева вверху)**:
   - Мгновенный выбор 4 погодных пресетов мира.
   - Слайдер длительности симуляции (от 5 до 120 секунд) с эргономичным нижним контролом.
   - Настройка PRNG Seed для 100% повторяемости.

2. 🔬 **Ground Truth Physics Lab (Слева по центру)**:
   - Прямой мониторинг истинных физических величин: $TWS$, $TWD$, $H_s$, вертикальный Heave, истинный крен (Roll), истинный дифферент (Pitch), курс (Yaw), истинная скорость (SOG), угол руля и процент гидродинамического срыва пера (`RUDDER HYDRO LOSS`).

3. ⛵ **Vessel Preset & Sail Rig Configuration (Слева внизу под Ground Truth)**:
   - Выбор пресета судна: современный крейсерский круизер **Beneteau Oceanis 45** ($LOA=13.94$ м, $Beam=4.50$ м, $Mass=10550$ кг, $S=100\text{ м}^2$, $H_{\text{mast}}=19.5$ м) или классический монокорпус **IOR Classic 34ft** ($LOA=10.5$ м, $Beam=3.4$ м, $Mass=5200$ кг).
   - Интерактивный переключатель конфигурации парусов:
     - ⛵ **`CODE_ZERO` (130%)**: Легкий полноразмерный геннакер/код зеро для максимальной тяги на попутных/полных курсах.
     - ⛵ **`FULL_MAIN` (100%)**: Полный грот и стаксель для штатного крейсерского хода.
     - ⛵ **`REEF_1` (75%)**: Первый риф для свежего ветра.
     - ⛵ **`REEF_2` (50%)**: Второй риф для штормовых условий.
     - ⛵ **`STORM_JIB` (25%)**: Штормовой стаксель.
     - ⛵ **`BARE_POLES` (0%)**: Без парусов (дрейф под рангоутом).
   - Физический расчет 4-DOF динамики судна мгновенно учитывает площадь, плечо кренящего момента и тягу выбранного паруса.

4. 🧭 **6 Analog Marine Canvas Dials (Центральная консоль)**:
   - **Wind Gauge (AWA / AWS)**: Индикатор вымпельного ветра с цветовой разметкой левого/правого галса и мертвого угла (Eye of Wind).
   - **Heel Inclinometer**: Инклинометр бортового крена с динамическими зонами безопасного и критического крена (до $\pm 40^\circ$).
   - **Pitch Angle**: Инклинометр килевой качки (дифферента) с отображением волновых колебаний корпуса.
   - **Compass & Nav**: Навигационный репитер с истинным курсом (Heading), путевым углом (COG) и скоростью (SOG).
   - **Heave Displacement**: Графический монитор вертикальной качки на волнении.
   - **Hull Slamming G-Force**: Измеритель силы гидроударов волны (слеминга) и пиковых перегрузок.

5. 💡 **Skipper Interactive Query Loop (Справа над панелью решений СИА)**:
   - Двусторонний диалог между SIA Core и шкипером.
   - Запрос подтверждения текущего парусного вооружения (`FULL_MAIN`, `REEF_1`, `REEF_2`, `STORM_JIB`).
   - Оперативное уточнение контекста для перерасчета приоритетов рекомендаций.

6. 🛡 **SIA Core Advisory & Oracle Evaluation (Справа)**:
   - Матрица риска брочинга (Nominal / Precursor / Critical).
   - Рекомендации экипажу в реальном времени (Primary Action + Candidates).
   - Арбитраж Oracle: независимый вердикт **`PASS / FAIL`** с замером задержки реакции (Response Latency $< 250$ мс).

5. ⏱ **Interactive Timeline & Scenario Builder (Таймлайн)**:
   - Увеличенная на 25% высота для удобного позиционирования событий.
   - Отдельные дорожки для событий: `Wind Gust` (шквал), `Wave Impact / Slam` (гидроудар), `IMU Dropout` (отказ гироскопа), `GPS Fix Loss` (потеря сигнала спутников), `Rudder Stall` (заклинивание руля).
   - Клик по шкале времени для мгновенного добавления событий.
   - Скруббер времени с плавным воспроизведением (Play, Pause, Replay, покадровый шаг).

6. 🛡 **SIA Core Advisory & Oracle Evaluation (Справа)**:
   - Матрица риска брочинга (Nominal / Precursor / Critical).
   - Рекомендации экипажу в реальном времени.
   - Арбитраж Oracle: независимый вердикт **`PASS / FAIL`** с замером задержки реакции (Response Latency $< 250$ мс).

## 🌊 Физический движок и гидродинамика

* **Численное интегрирование**: Метод Рунге-Кутты 4-го порядка (RK4) с шагом $\Delta t = 0.01$ с.
* **4-DOF Планарная динамика**: Продольное движение (Surge), поперечный дрейф (Sway), рыскание (Yaw) и бортовая качка (Roll).
* **Килевая качка (Pitch)**: Аналитический расчет встречи с волновым склоном с учетом волнового числа, частоты встречи ($\omega_e$) и дифферента от слеминга.
* **Аэродинамика и гидродинамика**:
  - Аэродинамические поляры парусов (подъемная сила, лобовое сопротивление, кренящий момент).
  - Восстанавливающий момент остойчивости $GZ(\phi)$.
  - Нелинейное сопротивление корпуса и демпфирование качки.
  - Гидродинамическая потеря подъемной силы на пере руля при сильном крене (эффект аэрации).

## 🧪 Тестирование и контроль качества

Проект покрыт **204 автоматизированными тестами**:

* `test_sia_boundary.py` — AST-инспекция кода для гарантии отсутствия импортов `GroundTruthFrame` в модулях SIA.
* `test_physics_determinism.py` — Побитовое совпадение физических траекторий при идентичном сиде.
* `test_sensor_determinism.py` — Проверка статистических свойств шумов и независимости каналов.
* `test_simulation_runner.py` — Проверка детерминированного выполнения сценариев SIM-005 и BENIGN.
* `test_world_presets.py` — Тестирование всех 4-х пресетов морского мира на стабильность и отсутствие паразитных событий.

```bash
# Проверка качества кода (Ruff)
uv run ruff check src/ tests/

# Запуск тестов
uv run pytest
```
